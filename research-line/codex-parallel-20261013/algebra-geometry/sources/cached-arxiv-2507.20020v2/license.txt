WHAT THIS PACKAGE CONTAINS
* items/182256_author_proof.tex - one independent LaTeX document that reproduces, verbatim and in the
  article's own notation, the article's lem 5.13 (native source lines 1672-1689) together with the article's
  complete proof of it (lines 1690-1738, one proof environment of 49 lines). Retained uncounted as the source-local context the proof needs: lines 1605-1612; lines 1657-1660.
  Every retained line is the article's own line, unchanged; nothing was omitted from any retained span, so the package contains no omission record and declares no adaptation.
* Numbering as delivered: the wrapper declares the retained theorem-like environments on separate counters, so the retained items print as Proposition 1, Lemma 1 in order of appearance, whereas the article prints the same items with the numbering of its own full document; the retained lines contain no numbered display.
* No bibliography and no bibliography entry: no retained line contains a citation.
* Drawing material: the retained lines contain the article's own diagram code, which the wrapper typesets with the standard tikz packages; no image file is delivered.
* sources/182256/source0.tex - the complete native author source of the article as distributed in the arXiv e-print for this version. It is the article's own source as the pipeline concatenated it, byte identical to the e-print files apart from the single header comment line naming them; nothing else is added, removed or changed.
* an AMS amsart wrapper, its standard TeX Live packages, and this notice. These are editorial formatting only.

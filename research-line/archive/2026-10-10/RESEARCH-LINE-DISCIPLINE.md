# 研究级材料线的纪律（2026-10-09 立，全部来自实测）

> 适用于"逐条深读原始文献 → 产出完整题证单元"这条线（与 class-4 回收线的 runbook 分开）。
> 每条都标注**它来自哪次实测**，不写没有证据的原则。

## 一、选件：收承担者，不收招牌 ⭐

**规则**：拿到论文/书，**先问"决定性的一步（下界／存在性／核心构造）是由这条证明完成的，还是被引用的？"**
- **被引用 / 被推迟 / 只是改写 / 只是索引 ⇒ 至多 H2**（无论标题多响亮、作者怎么称它）
- **本证明承担 ⇒ 才谈 H3**

**五次实测（命中 4 次）**：

| # | 论文 | "招牌"的真实身份 | 处置 |
|---|---|---|---|
| 1 | NUMDAM（Ann. SNS Pisa 2013, Thm 2.1） | **一段话化归**到 Prop 3.4 | 改收 Prop 3.4 ✓ |
| 2 | MSP（Pacific J. Math. 2020, Thm 1） | **自足**（只引外部标准结果） | 收它 ✓ |
| 3 | AIF（Ann. Inst. Fourier 2024, Theorem I） | **结果索引**（四项各在别处证明） | 改收别处的定理 ✓ |
| 4 | Lurie（Ultracategories, Thm 3.1.5） | 作者自陈是经典事实的 **reformulation** | 不收 ✓ |
| 5 | Lurie（Ultracategories, Thm 3.4.4） | 明写 **"whose proof we defer to §3.5"** | 改收 **Prop 3.4.6** ✓（独立复核确认 H3 ✓） |

**⚠️ 前提（独立复核员补正）**：该规则**只在"推迟链终止"时**才成立 ——
即被指向的那条**自己不再往下推**。Lurie 的 §3.5 已逐页核实：四个引理全在 38–41 页内证明、节内无 defer 类措辞 ✓。
**若承担者又把活推走，则它同样至多 H2** ✓

**⚠️ 另一条边界（计划 §4.3）**：允许"跨页、非相邻段落、附录及**明确指向的续证**一并取得"，
但**指向另一条独立命题 ≠ 续证** —— 那种情况应把**被指向的那条**作单元，不要拼成一条 ✓

## 二、档位：口径必须统一，且换尺子后旧数字作废

**H3 的硬判据**：决定性一步由本证明承担（多步归约＋自行构造）✓
**H2**：决定性一步被引用，或实质是"构造＋一致性验证"／"归约＋精确记账" ✓
**H1**：过门槛但不到 H2 ⇒ **单列 HOLD，保留理由，不塞进计数** ✓
**不达档**：用独立标记 **`ineligible`**，**不许借用 H1** ✓

**⚠️ 实测的代价**：H3 判据 2026-10-09 收紧后，**同一来源、同一筛选方式下 H3 率从 75% 掉到 5%** ✓
⇒ **换尺子后，用它量过的所有旧数字都要作废重测**；报告里带"跨批不可比"标注 ✓
⇒ **并立刻在同一来源上跑一次对照批**，用对照组暴露不可比 ✓

## 三、H3 无法机械化筛选（两次被自己的数据证伪）

| 试过的信号 | 结果 |
|---|---|
| **引用密度**（`\ref{}` 次数/KB） | **H3 中位 2.40/KB vs H2 1.80/KB** ⇒ **方向与假设相反**，两组大幅重叠 ✗ |
| **证明开篇特征**（construct vs reduce） | H3：20%/20%；H2：17%/11% ⇒ **分布几乎重合** ✗ |

**⇒ 结论**：**"决定性一步由谁承担"是纯语义判断，只能逐条读** ✓
**⇒ 成本如实**：**一条 H3 的阅读成本 ≫ 一条 H2**（Lurie 那条花了约 7 轮）⇒ **H3 占比低是结构性的，不是筛选不聪明** ✓

## 五、PDF 来源的硬事实

- **文本层不可信**：`∈→2`、`≠→6=`、`α→↵`、`f'→f 0`、`²→2`、`(b_i−a_i)→(bi ai )`，**连小形大写标题都被揉成 `O PTIMAL`** ⇒ **只用于定位** ✓
- **正确做法**：`pdftoppm -r 150 -png` 渲染该页 → **读图逐字转录** → 与页面对照 ✓（原页图存 `raw/` 供复核 ✓）
- **来源需同时满足两条**：①研究级 ②**"定理＋紧邻完整证明"形态** ✓（实测 DROPS/LIPIcs 的会议论文定理/引理行数 0/6/3/1 ⇒ **试后否掉** ✓）

## 六、判定不能自证

**重要批次必须交独立判定员复核**，且**它们只读原文与理由、不看我的结论** ✓
**实测**：R1 我判 3 条 H3、**复核改判 2 条** ✗；Lurie 这条我判 H3、**复核 2/2 也判 H3** ✓
⇒ **复核是唯一能区分"我判对了"和"我以为我判对了"的手段** ✓

## 七、口径与命名的小规矩（都踩过）

- **id 要能唯一确定条目**：Stacks 有 **982/7741 的 label 跨文件重名** ⇒ 不唯一时用 **`<来源>-<文件名>-<label>`** ✓
- **文件名不带 `:`**（Windows）；**真实 id 写在文件内容里**；**收集侧按内容取 id** ✓
- **追加型脚本必须幂等**；**下游计数的文件优先做成派生**（本线 `index.jsonl` 已改为从 `reasons*.json` 重建 ⇒ 结构上不可能重复 ✓）
- **配对歧义拒绝猜测**：标 `UNRESOLVED` 并打印，然后**找当事人留下的定位信息**（文件+行号）来配对 ✓

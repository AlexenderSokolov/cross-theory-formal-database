\paragraph{Definition 6.}
For an $r\times m$ matrix $M$ with entries in $\{-,\widehat O,\widehat *\}$ we define the $r\times m$ Colored-Multi-Predecessor matrix $\operatorname{CMPred}(M)$ with entries in $\{\widehat O,\widehat *,O,*\}$ as follows. For any $i,j$ we define $\operatorname{CMPred}(M)_{i,j}$ to be:
\begin{itemize}
\item $M_{i,j}$ if $M_{i,j}\neq-$,
\item $*$ if the predecessor of $j$ on row $i$ is $\widehat *$ (that is, there is $j'<j$ such that $M_{i,j'}=\widehat *$ and for every $k$ such that $j'<k<j$ we have $M_{i,k}=-$), and
\item $O$ otherwise.
\end{itemize}
The distribution $\Pi$ on $r\times m$ matrices is defined as follows, for $m$ divisible by $w^r$. Divide row $i=1,2,\ldots,r$ in consecutive blocks of $w^i$ elements. For each block, pick a uniform element, and assign to it a uniform element from $\{\widehat O,\widehat *\}$. All the other elements are set to $-$.
Working with the alphabet $\{\widehat O,\widehat *,O,*\}$ allows us to reconstruct $M$ from $\operatorname{CMPred}(M)$, slightly simplifying the argument.

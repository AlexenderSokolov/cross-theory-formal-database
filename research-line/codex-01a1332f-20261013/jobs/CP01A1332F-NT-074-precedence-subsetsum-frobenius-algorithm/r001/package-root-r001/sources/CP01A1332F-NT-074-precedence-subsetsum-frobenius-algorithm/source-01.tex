\begin{statementtheorem}[Author Theorem3.4]
We can solve Weighted DAG Implications in time $f(k)n^{4\sqrt k}$.
\end{statementtheorem}
Weighted DAG Implications asks, given a DAG $G=(V,E)$ with node weights $w:V\to\mathbb N$ and parameter $k\in\mathbb N$, whether there is a closed set $S\subseteq V$ of weight exactly $k$, i.e., $w(S)=k$ (author Problem3.1).

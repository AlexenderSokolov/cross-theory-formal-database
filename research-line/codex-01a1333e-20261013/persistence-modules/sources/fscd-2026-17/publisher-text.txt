      Abstract
We introduce a new presentation of the intersection type discipline in which typing judgments derive
vectors of types rather than single types. The system uses binary relations to control the flow of
information between coordinates of these vectors. We refer to this presentation as system R. The
maximal length of type vectors assigned to variables serves as a reasonable notion of dimension for
system R, which allows for a natural stratification into fragments of bounded dimension.
    The present system lies strictly between two known bounded-dimensional systems: the multiset-
dimensional system, for which inhabitation is EXPSPACE-complete, and the set-dimensional system,
for which inhabitation is undecidable. Our main result is that inhabitation in bounded system R
is decidable in 2-EXPTIME, while for each fixed dimension, inhabitation is decidable in EXPTIME.
This result is based on a subformula property restricting the inhabitant search space. Unlike in
traditional intersection type systems, the proof of the subformula property requires careful treatment
of the additional information flow management capabilities.
    Finally, we argue that system R and its stratification is a valid presentation of the intersection
type discipline. First, by proving the subject reduction property for system R in each bounded
dimension, and second, by establishing a correspondence with the classical intersection type system
of Barendregt, Coppo, and Dezani-Ciancaglini.

 1      Introduction

Intersection type systems [5, 2] are important in the theory of typed λ-calculi and pro-
gramming languages [1]. Such systems are highly expressive, characterizing deep semantic
properties of λ-terms including normalization and solvability properties [1]. Due to their
enormous expressive power, the classical type theoretical decision problems, typability and
inhabitation, are undecidable for such systems. It is therefore of interest to investigate
bounding principles for intersection type systems in order to obtain decidable fragments,
which may be useful for applications (for example, type checking or program synthesis) or
interesting for understanding the borderline between decidability and undecidability or the
complexity of bounded fragments.
    In the present work we focus on the inhabitation problem: Given a type environment
and a type, does there exist a term having the type in the environment? Type inhabitation
can be understood as the search for a program (term) which satisfies a given specification
(type) under given assumptions (type environment), and inhabitation with intersection types
may serve as a foundation for program synthesis [11, 16, 9]. Inhabitation understood as
proof search has also been used as a guiding principle for the development of Kripke-style
semantics for intersection types [10].

           A notion of dimensional bound was introduced by some of the present authors [7] for
       intersection type derivations. Intuitively, dimension measures the maximal cumulative
       width (number of components) of intersection types introduced for subterms in a derivation.
       Dimension can be measured in two ways, depending on whether width is measured over sets
       of types or multisets of types. The former corresponds to the standard, idempotent treatment
       of intersection types, the latter corresponds to a non-idempotent treatment. Relative to each
       measurement system, we considered inhabitation under dimensional bound: given a type
       and a dimensional bound, does there exist a term having the type in the given dimension?
       A key result of [7] is that the dimension-bounded inhabitation problem is undecidable
       in set-theoretic dimension ([7], Theorem 28) but decidable and EXPSPACE-complete in
       multiset dimension ([7], Theorem 34). For any fixed dimensional parameter, the latter
       problem is PSPACE-complete. The main previous result concerning decidable fragments of
       the inhabitation problem for intersection types had been given by Urzyczyn [19], showing that
       the problem is decidable and EXPSPACE-complete in rank 2, and undecidable in all ranks k
       for k ≥ 3 (here referring to Leivant’s notion of rank [13]). All rank 2 typings are derivable in
       linear multiset dimension [7, Proposition 23] (meaning dimension n for an intersection type
       with n components). Therefore, bounded multiset dimension strictly generalizes the rank 2
       borderline: typings in bounded multiset dimension span all ranks.
           In this paper we introduce and study a system (denoted system R1 ) with bounded parallel
       intersection providing a strict generalization of the multiset dimensional system [7], extending
       (and deepening the analysis of) decidable inhabitation under dimensional bound. Intuitively,
       system R occupies a position between the set-theoretic and the multiset dimensional systems
       of [7], employing a combination of intersection types represented as vectors of types (which
       are non-idempotent) and as sets of types (which are idempotent). A technical novelty of
       the system is the use of relations specifying type vector transformations that, intuitively,
       capture information flow between types in a derivation, and which mediate between vectors
       of types and sets of types. Dimensionality in this system is measured by the maximal length
       of vectors of sets of types that can be used to type a variable. Our main technical result
       is that inhabitation in bounded dimension is decidable in 2-EXPTIME, and for each fixed
       dimension, inhabitation is decidable in EXPTIME. We have corresponding lower bounds of
       EXPSPACE and PSPACE, respectively, and leave open the problem of closing the gaps.

Related work. There are several intersection type systems with features that partially
overlap with those of system R. However, none of these systems combines a syntax-directed
Curry-style presentation with concise information flow management.
    So-called non-idempotent intersection type systems have been shown to have decidable
inhabitation [3]. These systems are fundamentally different from ours, since they have a linear
treatment of type assumptions. Linearity turns out to imply polynomial bounds on the depth
of inhabitants (in terms of the size of inhabited types), thereby rendering the inhabitation
problem much less complex (in NP) for such systems.
    The system λCIL by Wells et al. [23] (and its simplified version [24]) is a system in
Church-style with explicit type annotations in λ-binders where different derivations for the
same subterm are managed by means of records. A record of types with labels from I is
derived here by a record of terms of corresponding labels from I. Term syntax in λCIL is
enriched with record management capabilities, which we avoid in system R.
    Similarly to λCIL , the system by Liquori and Ronchi Della Rocca [14] is a system with
explicit annotations at λ-binders. It introduces terms in which variables in binders are
annotated with indices. These indices serve as pointers to binders in derivations, and the
binders in derivations contain types. Again similarly to λCIL , term syntax is enriched with
type derivation information to establish a Church-style calculus.
    The proof system for Intersection Logic presented by Pimentel, Ronchi Della Rocca, and
Roversi [15] features independent derivations in tuples led according to the same proof rules.
Effectively, this works like an intersection type system with vectors. However, the system
does not have proof terms and relies on explicit exchange and weakening rules. Another
version of the proof system is formulated in terms of a sequent calculus [18].
    The line of research on Intersection Logic [17, 18, 15] inspired the development of
a vector-based sequent calculus, which we refer to as (⊢IL ), along with corresponding Kripke
semantics [10] for Intersection Logic. Proof search in (⊢IL ) corresponds to inhabitation
in the system of Barendregt, Coppo and Dezani-Ciancaglini [2]. It is natural to compare
fragments of (⊢IL ) in which the length of vectors is bounded to the presented dimensionally
bounded system R. The most important difference is that in (⊢IL ) reorganization of vector
coordinates in assumptions is realized via inverse images of surjective functions (see rule
(R) [10, Figure 1]). For example, for the function f such that f (1) = 1 = f (2) the inverse
image of the vector ({a, b}) under f is f −1 (({a, b})) = ({a, b}, {a, b}). As a result, information
can only be duplicated or discarded, and there is no granular control over the relevant part
of assumptions. Establishing such granular control can be realized via relations, generalizing
functions, which is the exact aim of system R in the present contribution.

     Let F := form(Ā) ∪ {form(τ̄ ) | (y : τ̄ ) ∈ Γ} be the set of all subformulae of types and

k-dimensional vectors to consider in derivations is bounded by (N + 1)k .
     The decision procedure works as follows. First, we non-deterministically guess whether t
is of shape λx.u for some x and u, or of shape x u1 . . . un for some x ∈ dom(Γ) and some
u1 , . . . , un where n is bounded by the maximal nesting of the arrow type constructor to the

In each branch i, we non-deterministically guess the necessary relation Ri (bounded in
cardinality by k 2 ), type vector Āi , environment ∆i , and recursively decide whether the
judgment ∆i ⊢k ui : Āi is derivable for some ui .
     By the pigeonhole principle, if a type environment contains more than (N + 1)k variables,
some must have identical assigned vectors. In the non-deterministic guess of the shape λx.u,
if x is assigned the vector Γ(y) for some y ∈ dom(Γ), we can equivalently guess λx.u[x := y]
instead and remove the assumption on x.
     Overall, the space required by the alternating decision procedure is polynomial in (N +1)k ,
yielding an AEXPSPACE, or equivalently, a 2-EXPTIME decision procedure.                               ◀

    If we fix a dimension bound k, we obtain an EXPTIME inhabitation decision procedure.

▶ Theorem 38. For any k ∈ N, given Γ and Ā it is decidable in EXPTIME whether the

Proof. Similarly to the proof of Theorem 37, the number of distinct vectors in recursive

    The avid reader may wonder: why is the EXPSPACE inhabitation procedure A⟨d⟩ [7], which
respects a bound d on the multiset dimension, not suited for inhabitation in dimensionally
bounded system R? One immediate answer is given by the construction in the proof of
Lemma 41. Iterative intersection introduction strictly increases multiset dimension. This is
reflected in procedure A⟨d⟩ via multisets of simultaneous constraints with strictly increasing
cardinalities on intersection introduction.
    Still, the immediate answer is not satisfactory. The construction in the proof of Lemma 41
can easily be accommodated for by identifying redundant constraints. The modified inhabi-
tation procedure would remain in EXPSPACE.
    A key property of procedure A⟨d⟩ is that environments in simultaneous constraints are
monotone with respect to pointwise inclusion. That is, there is no need to strengthen type
assumptions. This is different for the system R for which in rule (⇒E) type assumptions of
premises are combined, including the action of a relation R. This violates the monotonicity
condition, and the EXPSPACE (or, alternating exponential time) argument is not applicable.
    Overall, the present notion of dimension lies strictly between the multiset dimension
(EXPSPACE-complete inhabitation [7, Theorem 34]) and set dimension (undecidable inhabi-
tation [7, Theorem 28]), while preserving decidability of inhabitation.

 6     Conclusion
We introduced a new syntax-directed intersection type system, which we call system R, related
to traditional systems [2, 21, 22], where typing judgments assign vectors of types rather than
single types. Special relations control information flow between vector components, allowing
precise tracking of information flow while keeping derivations syntax-directed and manageable.
Vectors also enable a natural restriction on derivations: only vectors of dimension at most k
are allowed, which is crucial for later results.
    This system fulfills the need for a formalism in which natural bound on a resource,
here, the number of information-flow channels corresponding to vector dimension, renders
inhabitation decidable. With the maximal dimension being part of the input, inhabitation is
2-EXPTIME decidable, and fixing it as a parameter yields an EXPTIME decision procedure.
Without a bound, inhabitation becomes undecidable [19], as typings in our system coincide
with ones in traditional systems. We also establish EXPSPACE-hardness when the maximal
dimension is part of the input, leaving the exact complexity as an open problem.

            An earlier system [7] imposes a similar dimensional restriction. We therefore provided
        a detailed comparison highlighting both conceptual similarities and key differences in ex-
        pressiveness and technical treatment, throughout which demonstrating that system R offers
        a simpler and strictly more comprehensive framework that is easier to use in practice.

        Further work. Determining the precise complexity of inhabitation in the setting of system R
        remains an open and challenging problem. Addressing it would require resolving subtle
        combinatorial issues that arise from the interplay of bounded resources and vector-based
        type structures, making this a promising direction for future research.
            Another important avenue of investigation concerns type inference for system R. Since
        the system incorporates features of both set and multiset interpretations of types, it is not
        immediately clear whether the typability problem falls into NP or PSPACE, as established for
        related systems by Dudenhefner and Rehof [8]. Studying this question could provide deeper
        insight into the algorithmic behavior of the system. Similarly to system Rel of de Carvalho [6,
        Definition 4.1], it is interesting whether binary relations in system R can be related to term
        evaluation by means of a Krivine machine. As the system λCIL by Wells et al. [23] was also
        developed in the context of type inference problems, it would be interesting to compare it
        with the current system on the technical level.
            As the system Rel of de Carvalho uses relations in its models, it is interesting to see how
        the binary relations in the current system R fit into this kind of denotational semantics.
            Finally, intersection type systems are often extended with subtyping, so developing
        a version of system R with subtyping presents another interesting direction. Such an
        extension could potentially support subject expansion and reduction under η-reduction, but
        it would also complicate the algorithmic analysis of type inference and inhabitation problems,
        requiring careful treatment to balance expressiveness and decidability.

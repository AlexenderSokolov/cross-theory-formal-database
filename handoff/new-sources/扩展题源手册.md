核查日期：2026-10-03（UTC）。这是一份可执行的来源扩展地图，不是 30,000 道合格题的采集结果或数量保证。本次没有批量下载、编译题证、创建条目编号、登录、上传 Git 或突破访问拒绝。

## 1. 如何使用这份扩展

本次保留 44 个导航条目。按当前作品目录与实际题证 README复核：9 条为已有来源、出版社、试点或平台管线的复核/扩展；另有 20 条具体刊物、5 条研究仓库、3 条出版社逐文许可线索、2 条归档路线和5条元数据服务在这份快照中未观察到对应来源记录。后35条只表示“本快照未观察到”，不声称是35个新可复用证明库，不证明项目此前从未查阅，也不保证其数学结果尚未收录。

复核使用 [source_works.jsonl](../catalog/source_works.jsonl) 的作品身份、题名/作者、来源URL及版本字段，与 [candidate_catalog.jsonl](../catalog/candidate_catalog.jsonl) 的实际状态、原题证 README、已有 source-plan/Lean试点交叉检查；[source_domains.json](../catalog/source_domains.json) 仅辅助辨认平台，不能单独决定刊物是否新增。结构化记录保存逐条匹配作品键、旧题ID与平台上下文；完整输入哈希见核查摘要。由于旧条目的题名/版本记录不全且尚未逐题数学核对，“未观察到”不证明语义唯一。PFR相关旧候选3015单独标为相关主题，不把较强Euclidean变体反例与有限群PFR形式化主结论误合并。

Documenta N001 已有题3406（DOI10.4171/DM/963），改为已有池复核路线；N002 是经Documenta已使用的EMS出版社内其他刊/年份线索。N006/N007分别是既有Cambridge/Springer出版社内期刊拓展。N008–N020虽未观察到具体刊物记录，但Mersenne/Episciences平台已有JEP/ALCO/AHL/AFST/LMCS；N022–N023与既有EJP/ECP同属IMS/Project Euclid体系。N042复用已有GitHub发现/固定版本平台。已有Stacks、SIGMA、ALCO、JEP、AHL、ALEA、Theory of Computing、LMCS、JMLR、Forum Sigma等不重新列作新来源。N026是既有mathlib试点路线，不能误称已有合格Lean题证交付。

角色说明：
- reusable_candidate：来源层面发现了允许再利用的政策或样例；每个具体题仍待完整题证、难度、版权、源格式、编译及去重检查
- mixed_article_gate / mixed_version_gate：许可、版本、内容或格式混合；必须逐文/逐文件通关
- discovery_only：只提供发现/书目/版本定位，或版权目前不支持公开题证改编；自身不贡献题数
- rights_hold：数学价值已见但公开复用授权尚未核实；先留出处，不能复制进公开正文

## 2. 优先取得什么

1. 先选 N024 EJDE 当前明确 BY4 的研究文，页面直接有 PDF/TEX 路线；N033 Lebl SCV 已有原生 TeX、明确文本 licence，但先与旧条目去重。EJDE 的旧专著版权独立核查。两者的格式优势不会使简单命题自动达标。
2. 同时轮换未观察到的具体刊物与逐文许可线索：数值/优化选 N008–N009 与 N004，表示/代数/几何选既有池 N001 及未观察到的 N010/N015，逻辑/理论计算选 N013/N016/N020，统计选 N022–N023，数学物理选 N018/N021，离散/计算几何选 N012/N025。选择一个完整期次或文献块后原序枚举，避免只挑容易抽取或知名定理。
3. N002–N007 是宽域补广的逐文许可线索。AMS/SIAM/LMS以及Cambridge/Springer/EMS均未在本次建立整库全文复用授权；ND只作发现，其他混合许可必须逐文且逐文件核实。只取实际版本 licence允许的具体副本。先获得整篇授权 PDF，公开原生 TeX存在则复用；没有源包时，可以忠实转录为可编译 TeX，但作者来源、原稿证据、逐页公式对照和整理说明不可省。单纯 PDF 图片嵌进 TeX 不满足可编辑题证目标。
4. 形式化副线选 N027–N030 的独立研究结果，N026 mathlib 的高阶专题模块。先固定环境与人类来源，再把实际本地核心放进证明包；导出/比较器/汇合包装不能独立记题。N031权限未清，暂不进入公开正文。
5. N034–N042 用来发现跨数学方向/年代/语言的版本、DOI 和源码，随后回到真正作者/刊物原件。元数据/综述/形式化蓝图有助定位，不替代完整证明。

以上是工作优先级建议，不是领域题额或每题学科标签。新增应用数学来源不要只收“用了某方法”的论文，而应收非例行的存在、误差、稳定性、结构、收敛或复杂度证明义务。

## 3. 不降门槛的规模估计

30,000 是目标，不可由 arXiv文章量、mathlib声明量、期刊卷数、PDF页数或 theorem/proof 正则匹配数保证。一个文献常有大量定义核查、工具helper、直接套大定理、重复版本、未完证明和无可复用授权材料，均要退出；主结果也可能核心已在先修假设中被拿走。

建议接手人先固定小型校准批（例如每个选中来源家族 10–20 篇完整论文或一个完整高级章节；这是拟议试样大小，不是预测产量）。按原文顺序记录：已枚举文献、可取原件、许可可复用、完整题证、超资格考试、语义唯一、可编辑及实编通过各阶段数量。记录实际耗时、版本/版权失败原因和继续位置。分母保留全部已枚举文献，不能删除失败候选后报告虚高产率。

只在真正试样之后，按来源块报告独立合格问题数/文献、各门损耗、人工核对时间和不确定范围；有明显方向差异就分块估计，不把最便利池的产率套全数学。未见数据前只使用本册的“高/低候选密度可能性”定性推断。若源格式或版权成为主瓶颈，扩大来源而不是拆 helper、放宽 H1、收无解题或把熟悉命题改写成多题。

## 4. 每个可计数问题的硬门

- H1/H2/H3 均明确超过通常博士资格考试；写 2–4 句具体难度理由，指出标准背景仍留下的非例行局部证明核心及其原文位置。期刊名称、术语、作者、长证明、Lean build 不代替理由
- 人类原命题、完整已有证明、必要定义与完整核心论证对应；不能只给 proof sketch、答案、提示、引用、模型补证或仍开放问题。修订稿/erratum 中变化的结论必须匹配
- 原文许可适用于实际选用的版本和文件；不得用另一个版本、出版社泛指“可自存”、模板 licence 或代码 licence 套全文。NC/SA等限制保留，ND依现行项目保守政策退出新合格库
- 可编辑 TeX须实编并对照作者 PDF；Lean须实际完整源码与固定环境，实编并核目标声明依赖的 axioms/sorryAx。导入原库现成目标定理，再 exact/simpa 的 wrapper 不计“新增本地核心”
- 计数单位为语义独立问题。预印本/期刊/会议/翻译/fork/port/TeX/Lean表示合并；等价命题、特例参数变化、重命名、辅助拆分、同一个核心的包装合并。自然语言和Lean分表示保留，不重复计题
- 最近数学/形式化仓库可能含 AI 生成或混合贡献。姓名/PR作者不是充分的人类来源证据；保存原创论文/原人类实现/贡献说明、PR与版本映射。证据不够则 hold，不因编译通过放行

## 5. 权利与访问：几条必须留在接手上下文里的边界

arXiv nonexclusive 仅支持 arXiv自己的分发，不授予公众进一步复用权；licence 要看具体版本。发布版可能 BY4而 arXiv旧版nonexclusive，此时不能简单把新版授权覆盖旧源包；只有能证明源文本受相应授权时才公开复用。[arXiv官方复用FAQ](https://info.arxiv.org/help/license/reuse.html)

NUMDAM 的公开访问不改变原有copyright；它仍是优秀文献导航但没有全站再分发通行证。Mersenne也容许不同许可（包括ND），不能只因同一平台就全按BY4。[NUMDAM条件](https://www.numdam.org/conditions/)，[Mersenne说明](https://www.centre-mersenne.org/en/about/)

N009有明确时间边界；N020允许ND例外；N043默认ND；N015官方policy为SA，不采用第三方发现目录的BY简写。N011的同页版权文字存在张力，逐件notice未解决前hold。NC与SA应是材料级字段，整个汇编不能另给一个宽松总许可来抹除限制。[SMAI-JCM政策](https://smai-jcm.centre-mersenne.org/page/scope-and-objectives_en/)，[ENTICS政策](https://entics.episciences.org/page/editorial-policy)，[EpiGA政策](https://epiga.episciences.org/page/a-propos)

商业专著、自由可读讲义和无 licence 作者PDF默认只作发现入口，除非另取得覆盖实际文件的明确授权。例如《Introduction to Soergel Bimodules》官方书目注明专属 Springer许可，不可因个别章节可读或高级内容丰富就公开复制；《Mathematical Logic and Computation》官方版权页也明确需书面再利用许可。这类书籍可以帮助找相同作者另行授权的论文/讲义，不贡献本次题数。[Soergel书目](https://link.springer.com/book/10.1007/978-3-030-48826-0)，[Avigad官方版权页](https://assets.cambridge.org/97811084/78755/frontmatter/9781108478755_frontmatter.pdf)

## 6. 本地交接的最小执行记录

下面是记录建议，不建立额外通用平台或预先研究标签。沿用现有项目状态/题号，来源家族ID Nxxx只用于本册导航，永远不当成新问题ID。

先建一份选中 source-block清单，内容为 source family、作品/卷期/章节范围、枚举顺序、实际版本、开始/继续位置、下载限制。现有原件和hash优先复用。小页metadata缓存不保存账号字段、session、cookie、token或raw HTML。

每份论文源包/书章至少保留：官方URL/DOI/arXivvN/halvN/commit、作者/集体、题名、许可URL及短事实性证据说明、原PDF/source hash、题面/证明/附录定位、文件级例外、取得日期。不能把本册的web检索缓存当已保存原件；实际收文后再生成本地证据文件。

仓库取得后可用 git rev-parse HEAD 锁commit，转成包含完整SHA的blob/tree链接；保存许可证、NOTICE/文件头及固定dependency manifests。clone后先读文件和构建配置，不盲跑作者shell脚本。Lean4项目按官方README指定工具链用lake build，之后查目标#print axioms与真实核心；Lean3项目单列环境。缓存可加速但不能代替源码来源或axiom检查。本次没有做这些build，不能沿用“通过”状态。

对论文 TeX：收齐main.tex/include/bib/class/figure等必需文件，先以官方PDF核source版本，再在受控环境实编，对照选题公式/图式/证明续页，记录编译命令和日志。不能使用模型重构一个新证明来弥补缺页/缺源或无解习题。

遇到访问拒绝、登录墙或验证码不继续绕路；公开政策允许但工具暂时失败，记确切URL/状态交给接手人。若某来源需创建API key、付款、条款显式接受或外部授权，不在本次替用户执行。对于限流，优先小页、缓存、顺序处理、Retry-After和最新header；不按本册某个旧速率长期硬编码。

## 7. API查询例子说明

所有URL示例均为官方文档支持的查询/路线构造示例，不声称本次已发出这些查询或跑通完整下载。只有来源政策/页面观察被核查。本次未取任何巨型dump。

- arXiv：cat:math.AP 可替换为其他 math子类或邻接理论类别；固定日期块后使用API/OAI枚举，再逐版本licence，source包是否真的TeX另看
- Crossref：bibliographic query仅用于找DOI，推荐再用已选期刊ISSN/年份块固定范围，追 update-to/erratum；metadata licence留空不表示授权
- HAL：搜索带file记录后追加精确作者/期刊/年份；返回license和files实际字段先从当前schema核查，别猜字段；文件级licence是关键
- OpenAlex：is_oa只做候选发现；每个location可能不同licence；回源前不计题。2026当前help与旧文档有变化，规模时必须查budget/分页参数
- zbMATH：本册给官方citation matcher例子；一般REST由当前Swagger/schema构造，显式条款接受需要操作者授权，本次没接受
- DOAJ：API文档本次403，未猜测schema；官网metadata仍可发现数学刊，再直接读刊物policy
- DataCite/Zenodo：version DOI、relatedIdentifiers和software archive帮助源码pin；metadataCC0不是论文/源包CC0

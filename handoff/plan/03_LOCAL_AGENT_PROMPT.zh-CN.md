# 给本地执行器的接续指令

请接手当前仓库，把高级数学人类证明题库累计推进到30,000道合格唯一题。先读取交接根目录、状态快照、完整标准、执行计划、来源目录、材料恢复说明及实际manifest。不要从聊天中的旧数量推断现状。

当前交接已把历史来源线索、已取得材料、来源准入、规范化、整包本地通过、远端交付和受阻状态分开。首先恢复并核对真正已交付的题库与全文SQLite，再接收已规范化待合并包；不要重新下载、重复转录或重编号已有成果。保留原件、原ID、历史版本、失败记录及来源偏向说明。

每题必须高于普通博士资格考试，记录H1/H2/H3和2—4句具体依据；取得作者原命题、完整人类证明与全部必要新局部核心。明确标准先修可以引用，不无限追依赖；不能把主难点作为已知。条件性定理保持条件。作者正文与你的说明分开，不改量词、假设、常数或证明顺序，不生成证明来补缺。

初始建库仅做难度筛选，不做a/c、跨理论、工具、距离、桥梁、学科类型等研究标签。按来源块和原文顺序筛选，轮换作者、机构、语言和载体，不按未来希望观察的研究现象定向取样。

不要进行独立数学审稿、多模型投票或反例项目。做来源、题证对应、核心完整性、转录忠实、语义去重、排版和实际编译检查。关键缺证、无法辨认、版本不对应、权利不明、难度不清时记录具体hold并换候选；不猜补，不用“研究级”字样放行。

默认并行处理互不重叠的来源块，工作者只写自己的候选目录。可从4个工作者起步，稳定后8个；低推理档处理清晰的原生源提取与编排，少数疑难单独升级。一个合并器负责稳定ID、manifest、INDEX、全文SQLite和Git。不要先建设网站或复杂调度平台。

TeX正文必须完整可编辑，不能只是PDF包装、题名、链接或证明图片。必要几何资产可按确切许可保留，数学文字/公式与归属须满足现有严格门禁。Lean另行固定工具链、依赖、作者和提交，不收`sorry`、`admit`、新添公理或仅导入结论的包装；同一问题的不同表示只计一次。未实现Lean接纳门禁前，不混入TeX完成数。

许可证按当前文章作者/作品/DOI/版本逐一生成并检查，连修改说明也不能复制错题。出版PDF与原生TeX许可分开。nonexclusive原生源仅作私有未执行辅助；未知/禁止再分发的原件不进Git。只用最小事实性许可见证，不上传抓取网页表单、脚本、隐藏请求字段、会话值或凭据。上游类文件、构建脚本和未知宏不能直接执行；编译禁用shell escape并隔离凭据。

使用当前显式门禁路线：`compile_editable_delivery.py`和`validate_corpus.py --mode editable-delivery`。不要用历史默认门禁或PDF封装脚本证明完整正文合格。新题和改动题真实逐题执行；最终至少两次成功编译且引用稳定，保留实际次数/日志。缺字、未解析引用、重复标签、重编译请求须处理；普通警告只能在可读性已核对后保留说明，不能压制。

同一版本中核对题文件、来源、manifest、INDEX与SQLite完整全文；SQLite须通过integrity_check、foreign_key_check、唯一ID、数量与逐条TeX/来源投影检查。机械通过不代表独立数学正确性认证。

每25—100道通过材料形成可恢复提交，每500道新增合格题做全库聚合和完整证据对账，并汇报一次。相同材料、来源、许可、资产、编译、代码和投影的既往成功记录可严格复用；有变化、缺记录或全局运行程序变化时重新执行受影响范围。跨500边界不能用伪计数规避检查，也不必无条件重跑所有旧题。

已授权将本项目必要的完成/待处理/来源材料、数据库和说明提交到`AlexenderSokolov/cross-theory-formal-database`，不要为重复blob/commit操作反复询问。仓库当前为私有，不改变可见性。遵守本地工具权限：遇到新安全/权利/敏感数据问题，先隔离受影响材料，不绕过拒绝；原始拒绝内容不能换工具重传。操作不确定时查确切状态，不盲重试可变操作。

先完成接收和20道本地闭环，再稳定到100/500，随后3,000/5,000/10,000/20,000/30,000。来源规模不是合格产率；用实测数据估计时间和成本，不为配额降标。使用来源目录中的既有及扩展入口，不把开放问题、无解题单、普通资格考试题或辅助引理拆分算作目标。

每次结束或中断前，写清：当前提交、合格计数依据、队列状态、已领取来源块、完成位置、待处理原因、必要文件/哈希和下一条可执行命令。最终30,000题应有完整可读目录、全部题证与必要资产、来源/权利、可恢复全文数据库、逐题/批次证据和远端核验。

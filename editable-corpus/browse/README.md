## 怎样读一道题

1. 打开目录行中的题证／条目；旧TeX包直接给出正文，新共享条目给出固定作品与题面、证明、上下文范围。
2. 有已有阅读PDF或证明行链接时直接打开；必要定义、专门支撑引理仍以条目原记录为准。
3. Lean保持原源码、工具链与运行状态；未运行不等于缺失，也不能称为已验证。TeX篇幅以实际原文或PDF为准。

## 给网页端GPT与合作者

先提供本页与选题要求，再沿格式目录读取相关分页和每页JSON；不要一次要求抓取巨大manifest或全量catalog。题名关键词只用于初筛，入选前实际阅读题面、完整作者证明和必要上下文。每页最多100条且MD/JSON不超过64 KiB。当前目录不自动判断学科或跨理论；证明深度不能只看长度、标签或Lean imports。

使用Git固定版本链接记录所选题；链接无法读取时只补对应分页或题证文件，无需上传整个仓库。作者负责原数学，本项目整理来源与材料；明确缺口应如实保留，不由模型补证。

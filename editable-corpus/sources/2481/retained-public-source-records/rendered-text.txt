1 Introduction
1.1 Background
It was noticed a little more than a decade ago [7, 12] that two seminal theorems of Erdős and Szekeres from their 1935
paper [8]—the monotone subsequence theorem and the cups-caps lemma—can be cast as Ramsey theoretic statements
about monotone paths in two- and three-uniform hypergraphs, respectively. A tight monotone path of length n in a
k-uniform hypergraph on [N ] is the set of n edges which contain k consecutive vertices from v1 < v2 < · · · < vn+k−1
in [N ], and we will denote by M Sk (n; r) the least integer N such that every r-coloring of [N ](k) contains a tight
monochromatic monotone path of length n, i.e. a monotone path in which every edge receives the same color. (Here
and throughout, for a natural number N , we will denote by [N ] the set {1, 2, . . . , N }, and for a set X and a natural
number k, by X (k) the set {e ⊆ X : |e| = k}.) In this language, the theorems of Erdős and Szekeres read as follows.
Theorem 1.1 (Erdős–Szekeres, 1935 [8]). For all positive integers n ≥ 3 and r ≥ 2, we have

2.2 Majority tournaments
A tournament is a directed graph T = (V, E) where every two vertices u, v ∈ V are connected by one edge, i.e.
|E ∩ {(u, v), (v, u)} | = 1. If the edge is (u, v) (denoted by u → v) we say that u dominates v.
Definition 2.1. For an integer K ≥ 2, a tournament T is called a K-majority tournament if there exist 2K − 1 linear
(total) orders ≺1 , ..., ≺2K−1 on the set of vertices of T such that u → v in T if and only if v ≺i u holds for at least K
values of i ∈ {1, . . . , 2K − 1}.
    These types of tournaments have been studied in social science [15] as well as combinatorics, where previous
researchers studied extremal problems regarding the sizes of induced transitive subtournaments [16] and dominating
sets [1]. If T is a tournament and X, Y are subsets of vertices of T , we say that X dominates Y if for every vertex y in
Y \ X there exists an x ∈ X such that x dominates y. If Y is the full set of vertices of T , then we call X a dominating
set of the tournament T . The domination number f (T ) of T is the smallest cardinality of a dominating set of T . It
is a classical fact (often attributed to Erdős, see for example [17]) that every tournament T on n vertices satisfies
f (T ) ≤ dlog2 ne. It is also known [2] that random tournaments on n vertices do not contain any smaller dominating
sets, so this estimate cannot be improved upon in general. Nevertheless, it turns out that K-majority tournaments
behave quite differently than random tournaments when it comes to their domination number f (T ). In [1], Alon,
Brightwell, Kierstead, Kostochka, Winkler proved the following result:

Theorem 2.2. If T is a 2-majority tournament, then

                                                       f (T ) ≤ 3.

In general, for every K ≥ 2, if T is a K-majority tournament, then

                                                   f (T ) ≤ CK log K

holds for an absolute constant C > 0.
   It turns out it is this phenomenon which is primarily responsible for the drop in the tower height in our estimates
from Theorem 1.5 and Theorem 1.6 when compared to the estimate from Theorem 1.2.

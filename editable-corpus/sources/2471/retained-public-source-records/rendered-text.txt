Definition 2.1 (CSP template/instance/assignment). We define a CSP template to be a finite set of predicates
Γ = {P1 , P2 , . . . , Pl } over a finite domain D, where for all i ∈ [ℓ], Pi has arity ki ≥ 0. An instance Φ = (V, C) of
the constraint satisfaction problem (CSP) associated with the template Γ (i.e., “Φ is an instance of CSP(Γ)”),
consists of a variable set V and a constraint set C. The variable set consists of n variables V = {u1 , u2 , . . . , un }.
The m constraints C = {C1 , C2 , . . . , Cm } each consist of a tuple of variables Cj = (uj,1 , uj,2 , . . . , uj,lj ) ∈ V lj and
an associated predicate P (j) ∈ Γ of the same arity lj . An assignment σ : V → D is said to satisfy the constraint
Cj if σ(Cj ) = (σ(uj,1 ), σ(uj,2 ), . . . , σ(uj,lj )) ∈ P (j) .
   We now define two computational problems associated with CSP(Γ) where an instance Φ of CSP(Γ) is given
as input.
Definition 2.2 (CSP decision/search problems). In the decision version of CSP(Γ), the objective is to decide if
there is an assignment to a given instance of CSP(Γ) that satisfies all the constraints. In the search version of
CSP(Γ), the objective is to output an assignment to a given instance of CSP(Γ) that satisfies all the constraints.
  We next define promise constraint satisfaction problems (PCSP). We begin by defining what a promise
template is.1

domain D1 and each Qi has arity ki over domain D2 . Furthermore, we assert there exists a map h : D1 → D2

Definition 2.4 (PCSP instance/assignments). In an instance Φ = (V, C) of PCSP(Γ), we have a set of n

   A P -assignment is a map σ1 : V → D1 and a Q-assignment is a map σ2 : V → D2 . A P -assignment σ1 is

we often state Γ = (P, Q) and write PCSP(P, Q) for PCSP(Γ). The following are computational problems
associated with instances of PCSP(Γ).
Definition 2.5 (PCSP problems). In the decision version of PCSP(Γ), given an input instance Φ = (V, C) of
PCSP(Γ), the objective is to distinguish between the two cases.
    (1) There is a P -assignment σ1 : V → D1 that strongly satisfies all the constraints.
    (2) There is no Q-assignment σ2 : V → D2 that weakly satisfies all the constraints.
   In the search version of PCSP(Γ), given an input instance Φ = (V, C) of PCSP(Γ) with the promise that there
is an assignment σ1 : V → D1 that strongly satisfies all the constraints, the objective is to find an assignment
σ2 : V → D2 that weakly satisfies all the constraints.2
   An algorithm for PCSP(Γ) is said to be f -robust algorithm for a function f : R → R if the following holds.
The inputs to the algorithm are an instance Φ = (V, C) of PCSP(Γ) and a parameter ϵ with the promise that
there is an assignment σ1 : V → D1 that strongly satisfies 1 − ϵ fraction of the constraints. The objective of
the algorithm is to output an assignment σ2 : V → D2 that weakly satisfies at least 1 − f (ϵ) fraction of the
constraints. We call an algorithm a robust algorithm for PCSP(Γ) if it is f -robust for some monotone and
non-negative function f with f (ϵ) → 0 as ϵ → 0.

                                                    6. The SDP minion
   As previously mentioned, polymorphisms are a powerful tool for understanding the computational complexity
of PCSPs. However, beyond some of the simplest classes of PCSPs, individually classifying the complexity based
on specific polymorphisms can be unwieldy. Instead, one often looks to higher-level structure between classes
of polymorphisms, which is captured by the notion of minions (also called clonoids) [6].
   In this section, we describe the structure of the “basic SDP minion,” which gives a precise algebraic con-
dition for when the basic SDP decides a Promise CSP. We note that a similar minion was concurrently and
independently discovered by Ciardo-Zivny [26].
   We prove our minion characterization for “ordinary” promise constraint satisfaction problems over any do-
main. In particular, we do not consider instances with folding or the setting of constants.
6.1. Minion preliminaries. We now give the definition of a minion. This is most easily stated in the language
of category theory, however we shall also give “concrete” interpretations of any category-theoretic statements
we make. We let Set denote the category of sets, and NeFinSet denote the category of non-empty finite sets.
Definition 6.1. A minion M is a functor from NeFinSet to Set. More concretely, for every non-empty finite
set A, we let MA denote the image of A with respect to the functor. For every pair of non-empty finite sets A
and B and function π : A → B, we let the minor map Mπ : MA → MB denote the image of π with respect to
the functor. Further, for any maps π : A → B and τ : B → C, we have that Mτ ◦ Mπ = Mτ ◦π . We also assert
for the identity map idA : A → A, we have that MidA : MA → MA is also the identity map.
  To streamline the minor map notation Mπ , for all M ∈ MA , we let π ⊘ M := Mπ (M ) ∈ MB .
Remark 6.2. Some works only use minion (or clonoid) to refer to sets of the form Pol(Γ) for some (possibly)
promise template Γ, and refer to all other minions as an abstract minions. In this work, all such objects are
minions.
   In addition, M is typically only defined as a functor from the subcategory of NeFinSet of sets of the form [k]
for some k ∈ N. Our definition is equivalent as every non-empty finite set A has a bijection with [|A|]. However,
we consider this richer definition of a minion so that we can discuss how the minion acts on sets without an
explicit enumeration.

6.1.2. Minion homomorphisms. A key approach of [6] is that to better understand PCSP(Γ), we can ask how
Pol(Γ) relates to other (abstract) minions. The most natural way to do that is via a minion homomorphism,
which in category-theoretic language is a natural transformation between two minions.

Definition 6.3. A minion homomorphism ψ : M → N between two minions is a natural transformation between
the respective functors. More concretely, for every non-empty finite set A, we have a map ψA : MA → N A
such that for every map τ : A → B and M ∈ MA , we have that

                                             τ ⊘ ψA (M ) = ψB (τ ⊘ M ).

In other words, the following diagram commutes:
                                                           ψA
                                                   MA            NA
                                                      Mτ            Nτ
                                                           ψB
                                                   MB            NB

  To assert the existence of a minion homomorphism from M and N , we write M → N . A key result of [6] is
that minion homomorphisms govern the computational complexity of PCSPs.

Theorem 6.4 ([6]). Let Γ1 , Γ2 be promise templates. If Pol(Γ1 ) → Pol(Γ2 ) then decision version of PCSP(Γ2 )
is polynomial-time reducible to PCSP(Γ1 ).

  Another result of [6] is that for any promise template Γ, Qconv → Pol(Γ) if and only if the basic LP solves
PCSP(Γ). Our goal in the remainder of this section is to prove an analogous result for the basic SDP.

6.1.3. The free structure. Let Γ be a promise template. One of the most important tools for understanding
minion homomorphisms of the form M → Pol(Γ) is the free structure [6]. Since in this paper we parameterize
our promise constraint satisfaction problems using promise templates rather than a pair of relational structures,
we restate the definition of a free structure in our language, which we call a free template. Given a relation
R ⊆ Dk , we define the free relation FM (R) to be a predicate of arity k over MD with the following property,
we have that (M1 , . . . , Mk ) ∈ (MD )k is an element of R if and only if there exists N ∈ MR such that for all
i ∈ [k], we have that
                                                     πi ⊘ N = Mi ,
where πi : R → D is the projection of R onto the ith coordinate.
  Given a promise template Γ = {(P1 , Q1 ), . . . , (Pl , Ql )}, we define the free template

                                   FM (Γ) := {(FM (P1 ), Q1 ), . . . , (FM (Pl ), Ql )}.

Recall that for a promise template Γ over domain (D1 , D2 ), there exists a map h : D1 → D2 such for every i ∈ [ℓ]
and x ∈ P , we have that h(x) ∈ Q. It is not obvious (nor necessarily true) that for FM (Γ) an analogous map
hM : MD1 → D2 necessarily exists. In fact, constructing hM asserts the existence of a minion homomorphism.
This is the fundamental property of the free structure.

Lemma 6.5 (Lemma 4.4 of [6]). M → Pol(Γ) if and only if FM (Γ) is a promise template.

   In the language of category theory, the free structure can be thought of as an adjoint functor. See the
discussion preceding Remark 4.5 in [6].

3 Quantum groups and Feigin homomorphisms
In this section we introduce the main objects underlying the present investigations: the quantum groups
associated to a symmetrizable Cartan matrix and the Feigin homomorphisms mapping them to quantum
polynomial algebras.

                                                          2
    Fix an index set I. Let A = (aij ) be an I × I Cartan matrix with symmetrizing matrix D = diag(d),
where d = (di : i ∈ I) is an I-tuple of positive integers. More explicitly, the entries of A have the
following properties:

   • aii = 2 for all i;
   • aij ≤ 0 for i 6= j;
   • di aij = dj aji for all i, j ∈ I.

Let Q denote the root lattice of a Kac–Moody root system Φ associated to A. Denoting by {αi }i∈I the
simple roots of Φ, Q is the free abelian group with basis {αi }. The pair (A, d) determines a symmetric
bilinear form (·, ·) : Q × Q → Z given on generators of Q by (αi , αj ) = di aij for i, j ∈ I. Let Q be an
acyclic quiver with vertex set I and recall the symmetrizing matrix D = diag(d), where d = (di : i ∈ I).
Write nij = nji for the number of arrows connecting vertices i, j ∈ I in Q and note that all such arrows
point in the same direction. We assume further that there are only finitely many arrows whose source
or target is the vertex i ∈ I. From the pair (Q, d), called a valued quiver, we define an adjacency matrix
B = BQ = (bij ) by the rule
                                        
                                        
                                        nij dj / gcd(di , dj )    if i → j in Q,
                                   bij = −nij dj / gcd(di , dj )   if j → i in Q,
                                        
                                        
                                          0                        if i = j.

Notice that the matrix B is skew-symmetrizable with skew-symmetrizing matrix D, i.e. di bij = −dj bji
for all i, j ∈ I. To connect with the previous section we will assume that the matrix B is related to the
Cartan matrix A by aij = −|bij | for i 6= j.

Fix a finite field F and an algebraic closure F̄. For each positive integer d write Fd for the degree d
extension of F in F̄. Note that with these conventions we may intersect Fd and Fd′ to get that Fgcd(d,d′ ) is
their largest common subfield. We now define representations of (Q, d) by assigning an Fdi -vector space
to each vertex i ∈ I and an Fgcd(di ,dj ) -linear map to each arrow from vertex i to vertex j. The finite-
dimensional representations of (Q, d) form a finitary, hereditary, Abelian category repF (Q, d) where
kernels and cokernels are taken vertex-wise, we refer the reader to [34] for more details.
    Recall that we work under the assumption that the quiver Q contains no oriented cycles. Then the
simple representations of (Q, d) may be labeled as Si (i ∈ I) where the only non-zero vector space is Fdi
at vertex i. The Grothendieck group K(Q, d) of repF (Q, d) has a Z-basis given by the classes αi = [Si ]
(i ∈ I) of the irreducible representations Si , in this way we identify the root lattice Q with K(Q, d).
Write [V ] for the isomorphism class of a representation V ∈ repF (Q, d) and write |V | for its dimension
vector, i.e. the class of V in K(Q, d). Define the height ht(V ) of a representation V as the length of any
composition series for V .

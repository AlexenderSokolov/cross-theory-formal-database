1 Introduction
We study the exceptional set estimate and a Furstenberg-type problem in prime fields. The main novelty of this paper
is that we prove, for these two problems, that the two-dimensional result implies all higher-dimensional results.

1.1 Background
We first introduce the two problems—the Furstenberg set problem and the exceptional set estimate in Euclidean space.

1.1.1 Furstenberg set problem

1.2 The problems in prime fields
In the remainder of the paper, we look only at the prime fields. Let p be a prime and Fp be the prime field with p
elements. Throughout the paper, A ⪅ B means A ≤ C(log p)C B for some large constant C (independent of p). A ≈ B
means both A ⪅ B and B ⪅ A. A ≲ B means A ≤ CB for a large constant C (independent of p). A ∼ B means both
A ≲ B and B ≲ A.

Definition 1.4. We say (s, t; n, k) is admissible if 1 ≤ k < n are integers and 0 ≤ s ≤ k, 0 ≤ t ≤ (k + 1)(n − k).
   The Furstenberg set problem can be formulated as follows:
Question 1. Suppose (s, t; n, k) is admissible. Find the largest F(s, t; n, k), so that

                                                inf          #E ≳s,t,n,k,ε pF(s,t;n,k)−ε                                 (3)
                                          E: (s,t;n,k)-set

holds for any ε > 0.
    In the above inequality, the implicit constant may depend on many parameters, but never depends on p. For
simplicity, we may view s, t, n, k as fixed parameters and write ≳s,t,n,k,ε as ≳ε throughout the paper. The dependence
on s, t, n, k will be mentioned when needed. We are interested in the behavior as p goes to infinity, so the goal is to
find the index F(s, t; n, k) for fixed (s, t; n, k).
    We see that the problem consists of two parts: for fixed (s, t; n, k),
  1. (Lower bound) show for any (s, t; n, k)-set E, we have #E ≳ε pF(s,t;n,k)−ε ;
  2. (Upper bound) show the existence of a (s, t; n, k)-set E, such that #E ≲ pF(s,t;n,k) .

   Based on Ren-Wang’s result (1), it is reasonable to make a conjecture in F2p .

for any ε > 0.

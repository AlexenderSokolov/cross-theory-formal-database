Remark 2.20. If Yλ is smooth then it is in general position by Lemma 2.8.
    The map H n−1 (Yλ ) → H n−1 (Yλ∗ ) is injective if n − 1 is even, and has a kernel if n − 1 is odd, and this
kernel is generated by the hyperplane class, see [12, Theorem 1.19]. The residue map identifies H n (Vλ )
with the primitive part of the cohomology of H n−1 (Yλ ). In particular, the composition H n (Vλ ) →
H n−1 (Yλ∗ ) is injective independent of the parity of n. From the diagram on [12, p. 79] it follows that the
latter map factors through H n (Vλ∗ ). In particular, H n (Vλ ) → H n (Vλ∗ ) is injective. Hence we can apply
the above proposition if Yλ is smooth. The values of λ for which Yλ is singular can be determined from

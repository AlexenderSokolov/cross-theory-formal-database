1.2 A local properties problem for difference sets
We study an arithmetic version of such local properties problems, suggested by Zeev Dvir (see [8]). We consider
sets of real numbers for which every small piece is ‘arithmetically unstructured,’ and we wish to understand
how arithmetically unstructured this local property requires the entire set to be. One measure of the extent to
which a set is arithmetically structured is the size of its difference set — roughly, sets with smaller difference
set relative to their size possess more arithmetic structure. So we consider sets for which every small subset has
a reasonably large difference set, and attempt to understand how large the difference set of the entire set must
be.
    We now make this precise. For a set A ⊆ R, we define the difference set of A to be

                                       A − A = {|a − b| | a, b ∈ A, a ̸= b}.

Note that we include only positive differences in A − A; this definition is somewhat nonstandard but more
natural for the problem we study. (When discussing the differences present in a set, we refer only to positive
differences, unless otherwise stated.)
     For integers n ≥ k ≥ 1 and ℓ ≥ 0, we define g(n, k, ℓ) to be the minimum value of |A − A| over all n-element
sets A ⊆ R with the property that every k-element subset A′ ⊆ A satisfies |A′ − A′ | ≥ ℓ; we refer to this
property as the (k, ℓ)-local property. (Note that the same definition can be used to define g(n, k, ℓ) even when ℓ
is not a nonnegative integer; then g(n, k, ℓ) = g(n, k, ⌈ℓ⌉). This makes certain results slightly more convenient
to state.) We think of k and ℓ as fixed and n as large, and we study the asymptotic behavior of g(n, k, ℓ) as
n tends to infinity. (In particular, in all asymptotic notation in this paper, n tends to infinity while all other
quantities are fixed; the implied constants may depend on k, ℓ, and any other stated parameters.)

on considering the systems of equations associated with such configurations and analyzing their linear algebraic
properties.


2 Proof of Theorem 1.6: A family of upper bounds on g(n, k, ℓ)
In this section, we prove Theorem 1.6 (our family of upper bounds). The structure of the proof is as follows:
let ℓ be as in Theorem 1.6. In order to show that g(n, k, ℓ) = o(nc ), we need to show that for all a > 0, for
all suﬀiciently large n we have g(n, k, ℓ) ≤ anc — i.e., there exists an n-element set A ⊆ R with |A − A| ≤ anc
satisfying the (k, ℓ)-local property. We will obtain such a set A using a random construction. In order to
ensure that our set A satisfies the (k, ℓ)-local property, for every k-element subset A′ ⊆ A, we consider the
‘configuration’ of equal differences formed by its elements. Our argument will then consist of two steps: first,
we show that using a random construction, we can obtain an n-element set A with |A − A| ≤ anc that avoids
all ‘bad’ configurations (where we classify configurations as good or bad based on certain properties). We then
show that any k-element subset forming a ‘good’ configuration necessarily contains at least ℓ distinct differences.
It then follows that the set A we constructed must satisfy the (k, ℓ)-local property, providing the desired upper
bound.
     In Subsection 2.1, we set up a few useful definitions (in particular, we formalize the notion of a configuration
of equal differences) and state these two steps more precisely (with definitions of which configurations we
consider good and bad). In Subsection 2.2, we describe our random construction and prove that it avoids all
bad configurations. In Subsection 2.3, we prove that any subset forming a good configuration contains at least
ℓ distinct differences, modulo a certain technical lemma; in Subsection 2.4, we prove this lemma.

2.1 Setup
We formalize the notion of a configuration of equal differences in the following way: we define a k-configuration
to be a collection of linear equations over R in the k variables x1 , …, xk , in which each equation is of the form
                                                   xi 1 − xi2 − xi 3 + xi4 = 0                                                 (5)
for some (not necessarily distinct) indices i1 , i2 , i3 , i4 ∈ {1, . . . , k} such that {i1 , i4 } ̸= {i2 , i3 }. We refer to such
an equation as a difference equality. (The name, as well as the reason we care about such equations, comes
from the fact that (5) is a rearrangement of xi1 − xi2 = xi3 − xi4 . The condition {i1 , i4 } ̸= {i2 , i3 } means that
we only consider equations that are not identically satisfied.)
    In the remainder of this subsection, we establish some useful definitions regarding k-configurations; using
these definitions, we then state our two main steps more precisely, as Lemmas 2.4 and 2.5.

2.1.1 Conventions
We first fix a few conventions regarding linear equations (working over the field R).
    We consider equations to be unique only up to rearrangement; for example, we consider (5) to be the same
equation as −xi1 + xi2 + xi3 − xi4 = 0, xi1 − xi2 = xi3 − xi4 , and xi1 + xi4 = xi2 + xi3 .
    Given a linear equation (∗) in x1 , …, xk , we define its content to be an expression ∗ (which is a linear
combination of x1 , …, xk ) such that (∗) is the equation ∗ = 0. (For any nontrivial equation (∗), there are
two ways to define the content of (∗), where each is the negative of the other; we choose one arbitrarily.) For
example, the content of the difference equality (5) is either xi1 − xi2 − xi3 + xi4 or its negative.
    We say that a variable xi appears in a linear equation (∗), or that (∗) involves xi , if the coeﬀicient of xi in
(∗) is nonzero. (For example, the equation x1 − x2 = 0 involves x1 and x2 , but does not involve x3 ; this remains
the case even if we write it as x1 − x2 − x3 + x3 = 0.) We also use the same terminology for linear expressions
∗ in place of linear equations (∗). Given a set I ⊆ {1, . . . , k}, we say (∗) is an equation on I if all variables xi
appearing in (∗) satisfy i ∈ I.
    We say linear equations (∗1 ), …, (∗t ) are linearly independent if their contents ∗1 , …, ∗t are linearly indepen-
dent (viewed as elements of the k-dimensional R-vector space with basis vectors x1 , …, xk ).
    Given linear equations (∗1 ), …, (∗t ), (∗) with contents ∗1 , …, ∗t , ∗, we say that the collection T =
{(∗1 ), . . . , (∗t )} implies (∗) if ∗ can be written as a linear combination of ∗1 , …, ∗t , i.e.,

                                                  ∗ = ε 1 ∗1 + · · · + ε t ∗t

for some ε1 , . . . , εt ∈ R. (The reason for this terminology is that this is equivalent to the condition that every
solution to T (viewed as a system of equations) is also a solution to (∗); however, we will not need this fact.)
We say T minimally implies (∗) if T implies (∗), but no proper subset T ′ ⊂ T does. (Equivalently, T minimally
implies (∗) if and only if (∗1 ), …, (∗t ) are linearly independent and the coeﬀicients ε1 , …, εt above are all nonzero.)
    We say two collections of linear equations C1 and C2 are equivalent if C1 implies every equation in C2 , and
C2 implies every equation in C1 .

2.1.2 Definitions for k-configurations
For a k-configuration C, we let Sol(C) ⊆ Rk denote the set of solutions to C (where we view C as a system
of linear equations over R). For each I ⊆ {1, . . . , k}, we let SolI (C) denote the projection of Sol(C) onto the
coordinates in I — in other words, we define

                                     SolI (C) = {(xi )i∈I | (x1 , . . . , xk ) ∈ Sol(C)}.

We refer to the elements of SolI (C) as I-solutions to C.
    We define the dimension of C, denoted dim(C), to be the dimension of Sol(C) as a R-vector space; similarly,
for each I ⊆ {1, . . . , k}, we define dimI (C) to be the dimension of SolI (C).
    We say a solution to C is generic if it does not satisfy any difference equalities other than the ones implied
by C. Of course, any solution to C must satisfy all equations implied by C, so a generic solution to C satisfies
all the difference equalities implied by C and no others. (This definition will be used to encapsulate what we
mean by a k-element set ‘forming’ a configuration of equal differences, as stated in the outline in the beginning
of Section 2.)
    We define an occurrence of a k-configuration C in a set A ⊆ R to be a solution to C consisting of distinct
elements of A; if there is an occurrence of C in A, we say C occurs in A. For I ⊆ {1, . . . , k}, we define an
I-occurrence of C to be an I-solution to C consisting of distinct elements of A.

2.2 Proof of Lemma 2.4
In this subsection, we prove Lemma 2.4 using a random construction (with the alteration method). Our
construction will make use of the following theorem of Behrend.

Theorem 2.7 (Behrend [1]). For every positive integer n, there exists a set S ⊆ {1, . . . , n} of size |S| = n1−o(1)
containing no 3-term arithmetic progression.

{1, . . . , ⌈anc ⌉ − 1}) and that every k-configuration that occurs in A is AP-free. So in order to prove Lemma
2.4, it will suﬀice to ensure that every k-configuration that occurs in A is c-light. (We automatically have that
every k-configuration that occurs in A is valid, as this is true for any set.)

Proof. Let d = dimI (C). First, we claim that there are at most sd I-occurrences of C in S. To see this, without
loss of generality assume I = {1, . . . , m} for some m. By solving C using reduced row echelon form, we can
find a list of indices i1 < · · · < id′ , where d′ = dim(C), such that every choice of values for xi1 , …, xid′ in R
corresponds to a unique solution (x1 , . . . , xk ) to C, and for each i ∈ {1, . . . , k}, the value of xi in this solution
depends on only the chosen values of xij for the indices ij < i. Then each choice of values for xij over all indices
ij ≤ m corresponds to a unique I-solution to C, so there must be exactly dimI (C) = d such indices. Finally, each
choice of values for these d variables xij in S provides at most one I-solution to C whose elements are in S, and
therefore at most one I-occurrence of C in S. There are sd such choices, so there are at most sd I-occurrences
of C in S.
    Now for each I-occurrence of C in S, the probability that all its elements are included in T is pm (as it
has m distinct elements, each of which is included in T independently with probability p). So by the linearity
of expectation, the expected number of I-occurrences of C in T is at most sd · pm . Since s = nc−o(1) and
p = n1−c+o(1) , we have
                                                sd · pm = ncd+m(1−c)+o(1) .
Since cd + m(1 − c) < 1 by the definition of a c-heavy part (and this quantity is a constant not depending on
n), we have sd · pm = o(n), as desired.

    Now for each c-heavy k-configuration C, fix some c-heavy part of C, which we denote by h(C). Then Claim
2.8 implies that for each fixed c-heavy C, the number of h(C)-occurrences of C in T has expected value o(n).
But the total number of k-configurations is a constant (depending on k but not n), since for any given k, there
are only finitely many difference equalities. So the total number of h(C)-occurrences of C over all c-heavy C has
expected value o(n) as well. Then by Markov’s inequality, this number is at most n with probability 1 − o(1).
    So with probability 1 − o(1), we have |T | ≥ 2n and there are at most n total h(C)-occurrences of C in T over
all c-heavy k-configurations C; this means that for suﬀiciently large n, there must exist a set T ⊆ S with both
properties. Fix such a set T , and let A be an n-element subset of T obtained by first deleting some element from
each h(C)-occurrences of each c-heavy C (which requires us to delete at most n elements), and then deleting
additional elements arbitrarily until we are left with exactly n elements.
    We have already shown that |A − A| ≤ anc and that no invalid or AP-containing k-configuration can occur
in A; this construction guarantees that no c-heavy k-configuration can occur in A (as any occurrence of a
c-heavy k-configuration C would contain a h(C)-occurrence of C). So A has all the claimed properties.

2.3 Proof of Lemma 2.5
In this subsection, we prove Lemma 2.5 (our lower bound on the number of distinct differences in a generic
solution to a valid k-configuration, in terms of the dimension of the k-configuration). We first establish a few
definitions that will be useful in this proof.
    Note that equations of the form xi1 − xi2 = 0, 2xi1 − 2xi2 = 0, and xi1 − 2xi2 + xi3 = 0 are all considered
to be difference equalities, since we do not require the indices in (5) to be distinct. We say a difference equality
is degenerate if it is of the form xi1 − xi2 = 0 for distinct indices i1 and i2 (equivalently, in (5) the sets {i1 , i4 }
and {i2 , i3 } are different but not disjoint), and nondegenerate otherwise. (Since we assume the k-configuration
C we work with is valid, all difference equalities it implies will be nondegenerate.)
    Given a nondegenerate difference equality (∗), we say that two variables xi and xj appear in (∗) with opposite
sign if (∗) can be written as xi − xj = xi′ − xj ′ for some i′ , j ′ ∈ {1, . . . , k}, and with the same sign if (∗) can be
written as xi + xj = xi′ + xj ′ for some i′ , j ′ ∈ {1, . . . , k}. This definition matches the intuitive meaning of these
terms; in the difference equality (5), xi1 appears with opposite sign as both xi2 and xi3 , and with the same sign
as xi4 .
    Given distinct indices i, j ∈ {1, . . . , k}, we say that a collection of linear equations i-certifies j if it implies
some nondegenerate difference equality in which xi and xj appear with opposite sign. (In particular, we say a
single difference equality i-certifies j if xi and xj appear in it with opposite sign.)

Proof of Lemma 2.5. We first make a convenient assumption on the ordering of the indices of x1 , …, xk : by
using reduced row echelon form to solve C (as a system of equations), we can find d distinct indices i1 , …, id

loss of generality that these indices are 1, …, d.
     We can calculate |A′ − A′ | in the following way: for each pair of indices (i, j) with 1 ≤ j < i ≤ k, we say

lexicographically smaller than (i, j) (i.e., either i′ < i, or i′ = i and j ′ < j), and a new difference otherwise. Note
that if a pair (i, j) corresponds to a repeated difference, then (a1 , . . . , ak ) satisfies a nondegenerate difference
equality of the form

                                                 xi − xj − xi′ + xj ′ = 0                                                (7)

for some i′ , j ′ ≤ i (here we do not necessarily have j ′ < i′ ) — i.e., a difference equality on {1, . . . , i} in which xi
and xj occur with opposite sign. Since (a1 , . . . , ak ) is a generic solution to C, this difference equality (7) must
be implied by C.
     Then |A′ − A′ | is precisely the number of pairs (i, j) corresponding to new differences. For each index i, we
will upper-bound the number of repeated differences contributed by i (i.e., the number of indices j < i for which
(i, j) corresponds to a repeated difference) by bounding the number of indices j < i for which C can imply a
difference equality of the form (7). Combining these bounds over all i will then give the desired lower bound
on |A′ − A′ |.
     We first consider the indices i ≤ d. Our assumption that every choice of x1 , …, xd corresponds to a solution
to C means that C cannot imply any equation on {1, . . . , d}, and therefore cannot imply a difference equality of
the form (7) for any j < i ≤ d. So each index i ≤ d contributes no repeated differences.
     We now consider the indices i > d. Fix some index i > d, let Si be the set of all difference equalities on
{1, . . . , i} involving xi that are implied by C, and let Si be a maximal linearly independent subset of Si . Then
Si implies every equation in Si , so if a pair (i, j) corresponds to a repeated difference, then Si must i-certify j
(as the corresponding difference equality (7) must be in Si , and is therefore implied by Si ).
     But we have dim{1,...,i} (C) = d, since each choice of x1 , …, xd corresponds to a unique solution to C. This
means we must have |Si | ≤ i−d (using the fact from linear algebra that a system of linear equations on i variables
consisting of s linearly independent equations has a solution space of dimension i − s). Then by Lemma 2.9, Si
i-certifies at most 2(i − d) indices, and therefore i contributes at most 2(i − d) repeated differences.

Remark 2.10. Lemma 2.5 is tight for d ≥ k2 + 1, as equality is achieved by the k-configuration

2.4 Proof of Lemma 2.9
In this subsection, we finally prove Lemma 2.9 (thus completing the proof of Theorem 1.6). Note that if the
collection S in Lemma 2.9 does not imply any difference equalities involving xi other than the ones already in
S, then the conclusion is obvious, as each difference equality in S individually i-certifies at most 2 indices. The
diﬀiculty comes from the fact that S may imply more difference equalities involving xi , which may i-certify
additional indices; the key observation that allows us to deal with this is the following lemma.

Lemma 2.11. Let T = {(∗1 ), . . . , (∗t )} be a valid collection of t linearly independent difference equalities, and
suppose that T minimally implies a difference equality (∗T ). Then the following statements hold:

  (i) At most 2t + 2 variables appear in T . Furthermore, if equality holds, then every variable appearing in T
      appears in exactly two of (∗1 ), …, (∗t ), (∗T ).

 (ii) For every proper subset T ′ ⊆ T of size t′ , at most 2t′ variables appear in T ′ but not T \ T ′ .

Proof. Let ∗1 , …, ∗t , ∗T be the contents of (∗1 ), …, (∗t ), (∗T ). Since T minimally implies (∗T ), there exist
nonzero ε1 , . . . , εt ∈ R for which

                                                 ∗ = ε 1 ∗1 + · · · + ε t ∗t .                                       (8)

     We first prove (i). Note that (8) implies that variable that appears in T must appear in at least two
of (∗1 ), …, (∗t ), (∗T ). But each of these t + 1 equations involves at most 4 variables, so there are at most
4(t + 1) appearances of variables with multiplicity. So the total number of variables appearing in T is at most
4(t+1)
   2    = 2t + 2, and if equality holds then each variable must appear exactly twice.
     We now prove (ii). For notational convenience, assume that T ′ = {(∗1 ), . . . , (∗t′ )}, and let

                                           ∗T \T ′ = εt′ +1 ∗t′ +1 + · · · + εt ∗t .                                 (9)

(In words, ∗T \T ′ is the partial sum of (8) corresponding to only the equations not in T ′ .) Then we have

                                           ∗T − ∗T \T ′ = ε1 ∗1 + · · · + εt ∗t .                                   (10)

Let (∗T \T ′ ) be the equation ∗T \T ′ = 0 (this is implied by T , but is not necessarily a difference equality).
   We now define three disjoint sets of indices:

   • Let I1 be the set of indices i for which xi appears in (∗T \T ′ ) but not (∗T ).

   • Let I2 be the set of indices for which xi appears in (∗T ) but not (∗T \T ′ ).

   • Let I3 be the set of indices i for which xi appears in T ′ , but not (∗T \T ′ ) or (∗T ).

Let I1 , I2 , and I3 have sizes m1 , m2 , and m3 , respectively.
     Then for every variable xi appearing in T ′ but not T \ T ′ , we must have i ∈ I2 or i ∈ I3 — if xi does not
appear in T \ T ′ , then by (9) it certainly does not apply in (∗T \T ′ ), so i is in I2 if xi appears in (∗T ) and I3
if it does not. This means the number of variables appearing in T ′ but not T \ T ′ is at most m2 + m3 , so it
suﬀices to show that m2 + m3 ≤ 2t′ .
     First, we claim that m1 + m2 + 2m3 ≤ 4t′ . To see this, for each i ∈ I1 ∪ I2 , since xi appears on the left-hand
side of (10), it must also appear on the right-hand side; this means xi appears in at least one equation in T ′ .
Meanwhile, for each i ∈ I3 , since xi does not appear on the left-hand side of (10) but does appear in at least one
summand on the right-hand side, it must appear in at least two; this means xi appears in at least two equations
in T ′ . Since each of the t′ equations in T ′ involves at most 4 variables, this means that m1 + m2 + 2m3 ≤ 4t′ ,
as claimed.
     On the other hand, we will show that m1 ≥ m2 − 1. First, (∗T ) involves at most 4 variables, as it is a
difference equality. Meanwhile, we claim (∗T \T ′ ) involves at least 3 variables. To see this, first note that ∗T \T ′
is not simply 0 (as T \ T ′ is nonempty and its equations are linearly independent). However, its coeﬀicients
must sum to 0, as this is true of every summand in (8). So (∗T \T ′ ) cannot involve only 1 variable, and if it
involved only 2 variables, then it would be of the form εxi − εxj = 0 for some ε ̸= 0 and i ̸= j, contradicting
the validity of T . So (∗T \T ′ ) must involve at least 3 variables. Finally, m1 − m2 is the difference between the
numbers of variables involved in (∗T \T ′ ) and (∗T ), so m1 − m2 ≥ 3 − 4 = −1.
     Combining these two bounds, we have 2(m2 + m3 ) − 1 ≤ m1 + m2 + 2m3 ≤ 4t′ . Since 2(m2 + m3 ) and 4t′
are both even, this means 2(m2 + m3 ) ≤ 4t′ , so m2 + m3 ≤ 2t′ , as desired.

Proof of Lemma 2.9. Write down all difference equalities in S. For each subset of S that minimally implies
some difference equality also involving xi , draw a box around this subset. We say the size of a box is the number
of equations it contains, and we say a box is big if it has size greater than 1 (each equation in S is automatically
in a box of size 1, as it minimally implies itself). An example is given in Figure 2.

                                                                 x1 − x4 − x11 + x12 = 0

                            x1 + x2 − x5 − x6 = 0

                            x1 − x3 − x5 + x7 = 0

                            x1 + x3 − x8 − x9 = 0

                                                              (∗3 ) : x1 − x12 − x16 + x17 = 0
                        (∗2 ) : x1 + x7 − x9 − x10 = 0

Figure 2: This figure shows an example of a possible S and the corresponding boxes. Here i = 1, and S consists
of the equations written in black. Each equation of S is in a box of size 1, and we have three boxes of size
3, which are drawn in blue, purple, and green and labelled with the difference equalities that they minimally
imply (named (∗1 ), (∗2 ), and (∗3 ), respectively). For example, the blue box minimally implies (∗1 ) because
(x1 − x2 − x3 + x4 ) + (x1 + x2 − x5 − x6 ) − (x1 − x3 − x5 + x7 ) = x1 + x4 − x6 − x7 .

     We will work with the ‘connected components’ of this picture, which we refer to as ‘blobs’ — to formalize
this, consider the graph on S in which two equations of S are adjacent if and only if there is some box containing
both of them. We say a blob is a connected component of this graph, and the size of a blob is again the number
of equations it contains. In the example in Figure 2, we have one blob of size 5 (the union of the blue and
purple boxes), one blob of size 3 (the green box), and one blob of size 1 (the one equation not in any big box).
     Then the blobs form a partition of S such that if S i-certifies an index j, then in fact some blob must
i-certify j (every difference equality involving xi that is implied by S is by definition implied by some box, and
therefore by the blob containing this box). We will show that for each blob, the number of indices it i-certifies
is at most twice its size.
     Clearly any blob of size 1 can i-certify at most 2 indices. Meanwhile, we will show that any blob of size
t > 1 can only involve at most 2t variables other than xi , and therefore can i-certify at most 2t indices.
     Any blob T of size t > 1 can be written as a union of big boxes T0 , …, Tr such that for each 1 ≤ p ≤ r,
the box Tp has nonempty intersection with T0 ∪ · · · ∪ Tp−1 . Let t0 = |T0 |, and for each 1 ≤ p ≤ r, let
tp = |Tp \ (T0 ∪ · · · ∪ Tp−1 )|; then t = t0 + · · · + tr . (Intuitively, we can imagine ‘building’ T by starting with
some big box T0 , and then repeatedly adding in big boxes T1 , …, Tr such that at each step, the next big box we
add overlaps with some previously added box; then for each p, we define tp as the number of new equations we
add to the growing blob when we add in Tp . In the example in Figure 2, for the blob of size 5, we can take T0
to be the blue box and T1 to be the purple box; then t0 = 3 and t1 = 2.)
     First, Lemma 2.11(i) implies that T0 contains at most 2t0 + 2 variables. Furthermore, equality cannot hold,
as xi appears in all t0 + 1 ≥ 3 of the relevant equations, so in fact T0 contains at most 2t0 + 1 variables.
     Meanwhile, for each 1 ≤ p ≤ r, Lemma 2.11(ii) applied to Tp \ (T0 ∪ · · · ∪ Tp−1 ) (which is a proper subset of
Tp ) gives that there are at most 2tp variables that appear in Tp but not T0 ∪ · · · ∪ Tp−1 . (Rephrased in terms of
the process of building T one box at a time, this states that when we add in the big box Tp — thus adding in
tp new equations to our growing blob — these tp new equations give us at most 2tp new variables.)
     So the total number of variables that appear in T is at most

                                        (2t0 + 1) + 2t1 + · · · + 2tp = 2t + 1.

Since one of these variables is xi , this means at most 2t variables other than xi appear in T , as desired.
    So for every blob, the number of indices it i-certifies is at most twice its size. Since the blobs form a partition
of S, this means the total number of indices i-certified by any blob is at most 2 |S|, as desired.

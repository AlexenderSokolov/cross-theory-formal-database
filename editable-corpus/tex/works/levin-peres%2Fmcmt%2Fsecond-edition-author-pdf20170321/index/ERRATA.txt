• (12.18): The eigenfunctions for SRW on the cycle given there
  satisfy fj = fn−j , so there are only 1 + ⌊n/2⌋ of them, for
  j = 0, 1, ..., ⌊n/2⌋.
     Replacing cosine by sine for j = 1, ..., ⌊(n−1)/2⌋ yields the re-
  maining eigenfunctions. This is needed in order to be sure what
  the spectral gap is. This error propogates to (12.19) where the
  eigenfunctions claimed to be independent are double-counted
  and the eigenvalues we claim are distinct are repeated. Sines
  are needed there as well.

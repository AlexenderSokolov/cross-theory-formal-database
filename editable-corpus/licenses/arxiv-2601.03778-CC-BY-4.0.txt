What this package contains. items/192245_author_proof.tex (the wrapper document),
sources/192245/source0.tex (the mechanically concatenated article source, byte-identical to
the cached original), manifest.json, delivery-evidence.json, INDEX.md, the corpus database
scripts (schema.sql, rebuild_database.py, restore_database.py, test_database.py,
test_restore_database.py) and this notice.

Retained spans, figures and completeness. Every excerpt of the article inside the wrapper is
an exact line-for-line copy of sources/192245/source0.tex; nothing inside those excerpts was
omitted, substituted or reflowed, and no omission receipt applies to this item. One figure
environment is retained: the article's own truncation diagram (source0.tex lines 92--113),
which the article draws with the standard LaTeX picture environment and which is delivered
inline as its own code, so it needs no external image file. No graphics-inclusion command
occurs inside any retained span and the package ships no image asset. The article's other
figure, which uses \epsfig to include a JPEG file that the e-print does not contain, lies
outside every retained span and is not delivered. Exactly one reference is delivered, the key
ZCC cited inside the retained theorem, transcribed character for character from the article's
own thebibliography block at source0.tex lines 343--346.

Publisher class and style files: none are shipped and none are used. The wrapper is the
standard AMS amsart class with the article's own macro definitions restated, and the paper's
preamble packages are otherwise the pinned AMS runtime; no publisher class file, upstream
script, font or unrelated artwork is redistributed.

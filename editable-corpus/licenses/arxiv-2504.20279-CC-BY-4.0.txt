1. WHAT IS RETAINED IN THIS PACKAGE
-----------------------------------
This package is an editable LaTeX projection of one theorem of the Work, delivered with its complete original
proof and with the source-local context required to read it. It retains:

  * the authors' own LaTeX source text, reproduced verbatim from the e-print source file source0.tex at the
    exact line spans recorded in delivery-evidence.json (method "exact_tex" for all three bodies), namely
    source lines 86--418 (the whole body from the Introduction to the line immediately preceding the counted
    theorem), 419--421 (the counted theorem) and 422--554 (its complete proof, which contains the authors'
    own Proposition 5.2 and its proof as an interleaved step, exactly as printed);
  * the authors' own abstract, keywords and subject classification, reproduced verbatim from source lines
    47--55 in the front matter of the delivered item;
  * the authors' own title, author and address lines, reproduced in the wrapper title block;
  * the authors' own macro block, \newtheorem declarations, section-number format, \numberwithin setting and
    list settings, copied verbatim from source lines 20--25, 28--31, 59--65 and 67--82;
  * the authors' own bibliography entries for the 21 works cited by the delivered text, transcribed verbatim
    from the article's own inline thebibliography at source lines 650--727 in the authors' own order and with
    the authors' printed bibliography numbers;
  * the authors' own numbering, so that every printed section, theorem, lemma, proposition, corollary, table,
    equation and citation number of the delivered unit coincides with the published version (the counted
    theorem is printed as Theorem 5.1, as in the published version).

3. NO PUBLISHER MATERIAL AND NO ARTWORK
---------------------------------------
The Work contains no figure, no diagram and no artwork of any kind, and none is included in this package; the
e-print source contains no \includegraphics and no \input. The Work's tables are the authors' own text tables
and are reproduced as source text. The Work is itself an amsart article, so no publisher class file, publisher
typesetting, upstream script or font of a publisher is used, shipped or redistributed, and no part of a
publisher PDF is redistributed. The bibliography transcription redistributes only the authors' own reference
list as it appears in their e-print.

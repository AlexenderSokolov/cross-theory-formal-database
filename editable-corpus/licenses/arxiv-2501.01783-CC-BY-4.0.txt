WHAT THIS PACKAGE CONTAINS
* items/171117_author_proof.tex - one independent LaTeX document that reproduces, verbatim and in the
  article's own notation, the article's lemma secnn:exp (native source lines 1866-1879) together with the article's
  complete proof of it (lines 1881-1998, one proof environment of 118 lines). Retained uncounted as the source-local context the proof needs: lines 1484-1491; lines 1497-1518; lines 1524-1531; lines 1687-1700; lines 1705-1716.
  Every retained line is the article's own line, unchanged; nothing was omitted from any retained span, so the package contains no omission record and declares no adaptation.
* Numbering as delivered: the wrapper declares the retained theorem-like environments on separate counters, so the retained items print as Lemma 1 in order of appearance, whereas the article prints the same items with the numbering of its own full document; the retained lines contain no numbered display.
* No bibliography and no bibliography entry: no retained line contains a citation.
* No image and no artwork: no retained line contains a figure environment or an image-inclusion command, and the retained text contains no TikZ or drawing code; the package declares no asset dependency.
* sources/171117/source0.tex - the complete native author source of the article as distributed in the arXiv e-print for this version. It is the article's own source as the pipeline concatenated it, byte identical to the e-print files apart from the single header comment line naming them; nothing else is added, removed or changed.
* an AMS amsart wrapper, its standard TeX Live packages, and this notice. These are editorial formatting only.  The article's own local macro style file jmlr2e.sty is shipped in the e-print; it is not redistributed here, and the wrapper restates only the declarations and macros that the retained lines use, copying them verbatim from that file.

WHAT THIS PACKAGE CONTAINS
* items/197982_author_proof.tex - one independent LaTeX document that reproduces, verbatim and in the
  article's own notation, the article's lemma lem:tail-map-euler (native source lines 550-564) together with the article's
  complete proof of it (lines 566-742, one proof environment of 177 lines). Retained uncounted as the source-local context the proof needs: lines 89-91; lines 425-448.
  Every retained line is the article's own line, unchanged; nothing was omitted from any retained span, so the package contains no omission record and declares no adaptation.
* Numbering as delivered: the wrapper declares the retained theorem-like environments on separate counters, so the retained items print as Lemma 1 in order of appearance, whereas the article prints the same items with the numbering of its own full document; the numbered displays of the retained lines print consecutively in order of appearance, whereas the article numbers its equations per section.
* No bibliography and no bibliography entry: no retained line contains a citation.
* Drawing material: the retained lines contain the article's own diagram code, which the wrapper typesets with the standard tikz packages; no image file is delivered.
* sources/197982/source0.tex - the complete native author source of the article as distributed in the arXiv e-print for this version. It is the article's own source as the pipeline concatenated it, byte identical to the e-print files apart from the single header comment line naming them; nothing else is added, removed or changed.
* an AMS amsart wrapper, its standard TeX Live packages, and this notice. These are editorial formatting only.  The article's own local macro style file hdrcurve.sty is shipped in the e-print; it is not redistributed here, and the wrapper restates only the declarations and macros that the retained lines use, copying them verbatim from that file.

WHAT THIS PACKAGE DOES NOT CONTAIN
No publisher class or style file is redistributed. No upstream script, no font and no unrelated artwork from any other source.  No content was deleted from any retained span..

only the editorial material described in the document's own scope paragraph.

WHAT THIS PACKAGE CONTAINS
* items/178090_author_proof.tex - one independent LaTeX document that reproduces, verbatim and in the
  article's own notation, the article's Theorem 1 (native source lines 724-735: every accumulation point of
  the sequence generated by the accelerated proximal PRS-SQP algorithm with dual ascent-descent procedures
  is a Karush-Kuhn-Tucker point) together with the article's complete proof of it (lines 736-777, one proof
  environment of 42 lines, adjacent to the statement); and verbatim the source-local context that proof
  needs, namely the six displayed defining and optimality relations (lines 311-313, 319-321, 331-333,
  342-344, 350-352 and 364-366), the first and third standing assumptions (lines 430-441 and 644-646), the
  three lemmas bounding the sequence, the multipliers and the proximity terms (lines 503-505, 529-536 and
  561-565) and the displayed KKT-type relation they produce (lines 608-614). Every retained line is the
  article's own line, unchanged; nothing was omitted from any retained span, so the package carries no
  omission record and declares no adaptation.
* Publisher class. The article is typeset with the Springer Nature class sn-jnl, whose class file
  sn-jnl.cls is shipped in the e-print. That class file is not redistributed in this package and is not
  used by it: the wrapper is an AMS amsart document that restates the article's own three environment
  declarations (theorem, lemma and assumption, each on its own counter exactly as the article declares
  them) together with the standard packages the retained lines need.
* Numbering as delivered: the retained environments print as Assumption 1, Lemma 1, Lemma 2, Lemma 3,
  Assumption 2 and Theorem 1 in order of appearance, whereas the article prints the same six items with the
  numbering of its own full document; the numbered displays of the retained lines print consecutively in
  order of appearance, whereas the article numbers its equations per section.
* sources/178090/source0.tex - the complete native author source of the article as distributed in the arXiv
  e-print for this version. It is byte identical to the e-print file HAP-PRS-SQP.tex except for the single
  header comment line the pipeline's mechanical concatenation prepends and except for one non-UTF-8 byte of
  that file, which the pipeline's lossy UTF-8 decode carried through as a replacement character; nothing
  else is added, removed or changed. That byte lies in a comment line inside the preamble and outside every
  retained span.
* an AMS amsart wrapper, its standard TeX Live packages, and this notice. These are editorial formatting
  only.

WHAT THIS PACKAGE DOES NOT CONTAIN
No image and no artwork: no retained line contains a figure environment or an image-inclusion command, and
the retained text contains no TikZ or drawing code; the article's two figures lie outside every retained
span and the package declares no asset dependency. No bibliography and no bibliography entry: no retained
line contains a citation. No publisher class or style file is redistributed: sn-jnl.cls is not part of this
package. No upstream script, no font and no unrelated artwork from any other source. No content was deleted
from any retained span.

The mathematical text is unchanged: no mathematics is written, repaired or re-derived, and the wrapper adds
only the editorial material described in the document's own scope paragraph.

1. WHAT IS RETAINED IN THIS PACKAGE
-----------------------------------
This package is an editable LaTeX projection of one lemma of the Work, delivered with its complete original
proof and with the source-local context required to read it. It retains:

  * the authors' own LaTeX source text, reproduced verbatim from the e-print source file source0.tex
    (sha256 a598928c3a19069a7c844c69806d47b9f02ccf9bf48d21f6bff2503401e08b02) at the exact line spans recorded in delivery-evidence.json: source lines 83-439
    (the Introduction, the whole of the problem-formulation and algorithm-design section, and the whole of
    the convergence-analysis section with Theorems 1 and 2 and their proofs), source lines 467-486 (the
    numerical-experiments section and the conclusion), source lines 488-599 (the supporting-lemmas section
    with Lemmas 1-3 and their proofs), source lines 600-617 (the counted statement, Lemma 4 [Optimality
    gap], printed as Lemma 4 in the version of record) and source lines 619-739 (the complete original
    author proof of that lemma, 121 lines, the longest proof block of the Work). All of these spans are
    delivered under the exact method "exact_tex" except the second, which is delivered under
    "reference_only_adaptation" with exactly ONE replacement, described in point 2;
  * the authors' own abstract, reproduced verbatim as the front matter of the delivered item (source0.tex
    line 79);
  * the authors' own macro and environment declarations, copied verbatim from the e-print preamble: the
    colour wrappers \def \jm, \def \HY and \def \hy (source0.tex lines 37-40) and the theorem
    declarations \newtheorem for Thm, Def, Lem, Ass, Rem, Cor, Pro, Alg and Prob (source0.tex lines
    43-52), each with its own counter and none sharing one, including the authors' own spelling
    "Alogrithm", which is reproduced literally; together with the authors' own xcolor, algorithm and
    algorithmic loads (source0.tex lines 31, 33-34) that their pseudocode needs;
  * the authors' own bibliography entries, transcribed verbatim from the BibTeX output CDC25_arXiv.bbl
    shipped in the e-print (32 entries, classic \bibitem form), in the order of that file, so that the
    printed numbers [1]-[32] are those of the version of record; the Work cites exactly those 32 keys in
    the retained spans and all 32 are carried; the Work's own bibliography is external (source0.tex lines
    743-744 call \bibliographystyle{ieeetr} and \bibliography{reference}), so no in-source
    thebibliography exists and nothing had to be excluded;
  * the authors' own numbering, so that every printed number of the delivered unit coincides with the
    published version: the numbered equations run (1)-(30) in source order (including (24)-(30) in the
    supporting-lemmas section), and Assumptions 1-3, Theorem 1, Theorem 2, Lemma 1, Lemma 2, Lemma 3, the
    counted Lemma 4, Remark 1 and Algorithm 1 print as in the version of record.

2. EDITORIAL ADDITIONS AND BOUNDED ADAPTATIONS (NOT AUTHOR MATERIAL)
-------------------------------------------------------------------
  * the AMS amsart wrapper preamble and page geometry supplied by the pinned runtime of this corpus, in
    place of the publisher class (see point 3);
  * the title block, the source-and-licence line and the editorial scope note at the head of the delivered
    item, and the editorial rounding of the printed section style:
    \renewcommand{\thesection}{\Roman{section}} and
    \renewcommand{\thesubsection}{\Alph{subsection}}, which reproduce the sectioning style of the
    version of record (sections I-V, subsections A., B.) so that the authors' own organisation sentence
    prints Section II, III, IV and V exactly as published;
  * the standard amsart theorem and proof punctuation (Theorem 1., Lemma 4 (Optimality gap)., Proof.) in
    place of the publisher's colon style (Theorem 1:, Proof:) and the amsart end-of-proof box; a
    typographic difference of the wrapper that changes no text;
  * exactly one reference adaptation, recorded in delivery-evidence.json: the use of
    \ref{Fig_comprison_OGT} at source0.tex line 479, whose label lies inside the Work's figure* float, is
    delivered as a hyperlink to the version PDF carrying the printed number 1 of the version of record,
    because that float is not delivered. No other reference of the retained spans points outside them and
    no other text was changed;
  * the Work's \appendix line (source0.tex line 487) is NOT delivered, because the publisher's class
    renders it as an unnumbered APPENDIX heading whereas amsart would restart the equation counter and
    print (A.1)-(A.7) instead of the published (24)-(30); consequently the authors' own heading
    "Supporting Lemmas" prints as VI in this wrapper instead of the unnumbered APPENDIX of the version of
    record. This is a heading-only difference and changes no theorem, lemma, equation, algorithm or
    reference number. The authors' preamble loads that nothing in the retained spans uses are likewise not
    reproduced (inputenc, fontenc, url, booktabs, amsfonts, nicefrac, microtype, graphicx, subfig,
    textcomp, epstopdf and balance).

These additions are formatting, provenance, numbering and runtime-compatibility only. No mathematical
statement, proof step, symbol, hypothesis or number of the Work has been written, repaired, re-derived or
altered, and the printed slips of the Work (including its comments inside the counted proof) are kept
literal.

3. NO PUBLISHER MATERIAL AND NO ARTWORK
---------------------------------------
The Work ships a publisher class file, ieeeconf.cls, and its manuscript declares
\documentclass[letterpaper, 10 pt, conference]{ieeeconf}. That class file is NOT used, NOT shipped and NOT
redistributed in this package: the wrapper is an editorial AMS amsart formatting layer that reproduces the
authors' own declarations and numbering as set out above. The Work contains exactly three graphics,
figure/traj_16.eps, figure/res_16.eps and figure/consensus_16.eps (source0.tex lines 446, 453 and 460,
inside the figure* float at source0.tex lines 440-465). That float and its three EPS files are NOT
delivered and NOT redistributed: no retained span of this package contains an \includegraphics command,
the package declares no asset dependency, and the compile receipt records an empty dependency set. The
delivery evidence of this item carries no "bounded_source_comparison" body and no fidelity receipt of any
kind; the only fidelity classes it uses are "exact_tex" for four of the five delivered spans and
"reference_only_adaptation" with the single replacement of point 2 for the remaining one, so no verbatim
text of the Work was omitted from any retained span.

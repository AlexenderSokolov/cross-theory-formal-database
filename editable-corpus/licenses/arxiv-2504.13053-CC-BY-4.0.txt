1. WHAT IS RETAINED IN THIS PACKAGE
-----------------------------------
This package is an editable LaTeX projection of one theorem of the Work, delivered with its complete original
proof and with the source-local context required to read it. It retains:

  * the authors' own LaTeX source text, reproduced verbatim from the e-print source file source0.tex at the
    exact line spans recorded in delivery-evidence.json (method "exact_tex"), namely source lines 173--786,
    787--1005 (the complete body from the Introduction to the line immediately preceding the counted theorem),
    1006--1011 (the counted theorem) and 1012--1071 (its complete proof);
  * the authors' own abstract, reproduced verbatim from source line 166 in the front matter of the delivered
    item;
  * the ten occurrences of forward cross-references that leave this unit, at source lines 214, 254 (twice),
    264, 364 (four times), 541 and 927 (twice), delivered as \href links to the abstract page of this exact
    version with the printed numbers retained (method "reference_only_adaptation", the adapted lines are set
    out in delivery-evidence.json), together with the renaming of one stray duplicate label at source line 266,
    which prints nothing;
  * the authors' own macro block, \newtheorem declarations, \numberwithin setting and paragraph settings,
    copied verbatim from source lines 15--17, 26, 29--38, 43--119 and 126--158;
  * the authors' own bibliography entries for the 49 works cited by the delivered text, transcribed verbatim
    from the e-print's own bibliography file v.7.bbl (61 classic \bibitem entries) in the authors' own order
    and with the authors' printed bibliography numbers, and the four \providecommand lines of that file;
  * the authors' own numbering, so that every printed section, subsection, theorem, lemma, proposition,
    remark, equation and citation number of the delivered unit coincides with the published version (the
    counted theorem is printed as Theorem 5.2, as in the published version).

2. EDITORIAL ADDITIONS (NOT AUTHOR MATERIAL)
--------------------------------------------
  * the AMS amsart wrapper preamble and page geometry supplied by the pinned runtime of this corpus, together
    with the named packages this unit needs (esint, enumitem, amssymb, amsthm);
  * a three-line declaration of the article's own Boondox calligraphic script family, because the wrapper loads
    mathalpha once with its own script option and the article's own option selects a script font with
    lowercase letters; the declaration restores exactly the mapping that mathalpha's scr=boondox option uses in
    this runtime, so that the article's script letters are set in the article's own script font and no glyph is
    missing;
  * the title block, the source-and-licence line and the editorial scope note at the head of the delivered
    item;
  * the page-comparison witness described in section 4 below, which is kept outside this package.

These additions are formatting, provenance and runtime-compatibility only. No mathematical statement, proof
step, symbol, hypothesis or number of the Work has been written, repaired, re-derived or altered, and the
printed slips of the Work are kept literal.

3. NO PUBLISHER MATERIAL AND NO ARTWORK
---------------------------------------
The Work contains no figures, no diagrams, no tables and no artwork of any kind, and none is included in this
package; the e-print source contains no \includegraphics and no \input. The Work is itself an amsart article,
so no publisher class file, publisher typesetting, upstream script or font of a publisher is used, shipped or
redistributed, and no part of a publisher PDF is redistributed. The bibliography transcription redistributes
only the authors' own reference list as it appears in their e-print.

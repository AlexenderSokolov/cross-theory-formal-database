WHAT THIS PACKAGE CONTAINS
* items/178803_author_proof.tex - one independent LaTeX document that reproduces, verbatim and in the
  article's own notation, the article's pullback lemma for quotient extensions (native source lines
  335-338), together with the article's complete proof of it (lines 340-368, one proof environment of 29
  lines, adjacent to the statement), and verbatim the displayed quotient-extension diagram that the
  statement invokes (lines 307-325). Every retained line is the article's own line, unchanged; nothing was
  omitted from any retained span, so the package carries no omission record and declares no adaptation.
* Drawing material: the retained lines contain the article's own commutative-diagram code. The wrapper
  loads the standard tikz and tikz-cd packages so that those diagrams typeset, and no image file is
  delivered: the package ships no graphics file and declares no asset dependency.
* Numbering as delivered: the retained environment prints in this document as Lemma 1 and the one numbered
  displayed relation of the retained lines prints as (1), whereas the article prints the same items with the
  numbering of its own full document.
* sources/178803/source0.tex - the complete native author source of the article as distributed in the arXiv
  e-print for this version. It is byte identical to the e-print file main.tex except that the pipeline's
  mechanical concatenation prepends one header comment line naming it; nothing else is added, removed or
  changed.
* an AMS amsart wrapper, its standard TeX Live packages, and this notice. These are editorial formatting
  only; the article itself is typeset with the AMS amsart class.

WHAT THIS PACKAGE DOES NOT CONTAIN
No image and no artwork beyond the article's own diagram code: the retained spans contain no figure
environment and no image-inclusion command. No bibliography and no bibliography entry: no retained line
contains a citation. No publisher class or style file, no upstream script, no font and no unrelated artwork
from any other source. No content was deleted from any retained span.

The mathematical text is unchanged: no mathematics is written, repaired or re-derived, and the wrapper adds
only the editorial material described in the document's own scope paragraph.

EDITORIAL WRAPPER
-----------------
The paper's own class is ieeeconf in conference mode on letter paper; that class
file is not redistributed and is not used to build this package. The wrapper
(amsart, 10pt, A4, geometric margins, hyperref without bookmarks) is this lane's
editorial formatting. It reproduces the paper's own macro block and the paper's
own four theorem-like environment declarations, copied verbatim from the paper's
preamble, so the delivered statements keep the paper's own numbering. The paper's
preamble loads algpseudocodex for its algorithm blocks; that package's dependency
fifo-stack is not installed in this runtime, so the two retained algorithm
environments are set with the algorithmicx package algpseudocode, which provides
every command the paper's algorithms use and prints the same statements in the same
order, with a typographic difference in the end-markers and line labels of the
algorithm blocks. These are formatting differences of the wrapper only and do not
alter any formula, symbol, hypothesis or argument.

* items/118687_author_proof.tex - one independent LaTeX document that reproduces, verbatim and in the
  article's own notation, the article's lemma rays (native source lines 272-279) together with the article's
  complete proof of it (lines 280-318, one proof environment of 39 lines). No further source-local context is needed: every cross-reference of every retained line resolves inside the two delivered spans.
  Every retained line is the article's own line, unchanged; nothing was omitted from any retained span, so the package contains no omission record and declares no adaptation.
* Numbering as delivered: the wrapper declares the retained theorem-like environments on separate counters, so the retained items print as Lemma 1 in order of appearance, whereas the article prints the same items with the numbering of its own full document; the retained lines contain no numbered display.
* No bibliography and no bibliography entry: no retained line contains a citation.
* Drawing material: the retained lines contain the article's own diagram code, which the wrapper typesets with the standard tikz packages; no image file is delivered.
* sources/118687/source0.tex - the complete native author source of the article as distributed in the arXiv e-print for this version. It is the article's own source as the pipeline concatenated it, byte identical to the e-print files apart from the single header comment line naming them; nothing else is added, removed or changed.

WHAT THIS PACKAGE CONTAINS
* items/200554_author_proof.tex - one independent LaTeX document that reproduces, verbatim and in the
  article's own notation, the article's lemma Q_SD (native source lines 417-424) together with the article's
  complete proof of it (lines 425-437, one proof environment of 13 lines). No further source-local context is needed: every cross-reference of every retained line resolves inside the two delivered spans.
  Every retained line is the article's own line, unchanged; nothing was omitted from any retained span, so the package contains no omission record and declares no adaptation.
* Numbering as delivered: the wrapper declares the retained theorem-like environments on separate counters, so the retained items print as Lemma 1 in order of appearance, whereas the article prints the same items with the numbering of its own full document; the retained lines contain no numbered display.
* No bibliography and no bibliography entry: no retained line contains a citation.
* No image and no artwork: no retained line contains a figure environment or an image-inclusion command, and the retained text contains no TikZ or drawing code; the package declares no asset dependency.
* sources/200554/source0.tex - the complete native author source of the article as distributed in the arXiv e-print for this version. It is the article's own source as the pipeline concatenated it, byte identical to the e-print files apart from the single header comment line naming them; nothing else is added, removed or changed.
* an AMS amsart wrapper, its standard TeX Live packages, and this notice. These are editorial formatting only.  The article's own local macro style file quiver.sty is shipped in the e-print; it is not redistributed here, and the wrapper restates only the declarations and macros that the retained lines use, copying them verbatim from that file.

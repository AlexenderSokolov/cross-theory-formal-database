1. WHAT IS RETAINED IN THIS PACKAGE
-----------------------------------
This package is an editable LaTeX projection of one lemma of the Work, delivered with its complete original
proof and with the source-local context required to read it. It retains:

  * the authors' own LaTeX source text, reproduced verbatim from the e-print source file source0.tex
    (sha256 50ac732658e9703a8facc241eff1a32521548aa9a39ff43465f61921bec4325a) at the exact line spans recorded in delivery-evidence.json: source lines 139-1503
    (the whole body of the Work from the first line of its Introduction to the line before the counted
    statement, retained as the necessary complete source-local core and not counted), source lines 1504-1507
    (the counted statement, printed as Lemma 3.2 in the version of record) and source lines 1508-1625 (the
    complete original author proof of that lemma, 118 lines). The first span is delivered under
    "reference_only_adaptation" with exactly ONE replacement, described in point 2; the counted statement and
    its proof are delivered under the exact method "exact_tex";
  * the authors' own abstract, key words line and AMS subject classification line, reproduced verbatim as the
    front matter of the delivered item (source0.tex lines 120, 123 and 125);
  * the authors' own macro, environment and package declarations, copied verbatim from the e-print preamble:
    their tikz and float loads (source0.tex lines 14 and 13), their per-section theorem declarations
    \newtheorem for theorem, lemma, remark, result, prop, definition, cor and eg (source0.tex lines 44-51)
    together with the theorem-numbered example environment (source0.tex line 58), their
    \numberwithin{equation}{section} (source0.tex line 52), their end-of-proof box macro \cvd (source0.tex
    lines 27-28) and their macro block \reals, \complex, \mr, \MR, \rk, \nlt, \col, \row, \e, \det,
    \sgn, \In, \Ch, \min, \max, \RIn and \dist (source0.tex lines 61-85). One formal substitution is
    disclosed: the nine macros that the authors declare with \newcommand (\reals, \complex, \mr, \MR,
    \rk, \nlt, \col, \row, \e) are re-declared with \def carrying exactly the authors' own replacement
    texts, because \MR is already defined by the AMS packages that the wrapper loads and \newcommand would
    abort the compile; each macro expands character for character to the authors' own replacement text;
  * the Work's twenty-five figure environments, of which the sixteen inside the retained spans are delivered
    as the authors' own TikZ code (two of them inside the counted proof, at source0.tex lines 1519-1550 and
    1564-1590, and fourteen more inside the retained context), while the nine after source0.tex line 1625 are
    not delivered;

    the manuscript): exactly the five live entries that the retained spans and the reproduced abstract cite

3. NO PUBLISHER MATERIAL AND NO ARTWORK
---------------------------------------
The Work is an article-class manuscript prepared for the Electronic Journal of Linear Algebra (source0.tex
line 13 reads \documentclass[a4paper,10pt]{article}) and the e-print archive ships no class or style file at
all, so no publisher class file exists, is used, is shipped or is redistributed here; the wrapper is an
editorial AMS formatting layer. The Work contains no \includegraphics and no external graphic file: the Work
has twenty-five figure environments, of which the sixteen inside the retained spans are delivered as the
authors' own TikZ code (two of them inside the counted proof at source lines 1519-1550 and 1564-1590,
fourteen more inside the retained context), while the nine after source line 1625 are not delivered; no
artwork file is copied into this package or redistributed with it, no retained span contains an
\includegraphics command,
the package declares no asset dependency and the compile receipt records an empty dependency set. The Work's
source contains exactly five non-ASCII characters (four en dashes inside bibliography entries and one right
single quotation mark inside the retained text at source0.tex line 1302); all of them lie inside delivered
spans and all of them are rendered by the pinned xelatex runtime, so no glyph is missing and no character was
transliterated.

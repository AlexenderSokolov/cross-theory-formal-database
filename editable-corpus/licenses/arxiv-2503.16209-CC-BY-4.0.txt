WHAT THIS PACKAGE CONTAINS
* items/175107_author_proof.tex - one independent LaTeX document that reproduces, verbatim and in the
  article's own notation, the article's Theorem 2.8 (native source lines 396-403, printed as Theorem 2.8:
  the sampling-complexity guarantee for square-root Lasso and orthogonal matching pursuit function recovery
  with an L_q error bound for all 2 <= q <= infinity) together with the article's complete proof of it
  (lines 405-442, one proof environment of 38 lines, adjacent to the statement); and verbatim the
  source-local context that proof needs, namely the paragraph defining the measurement matrix and sample
  vector (lines 256-262), the definition of the square-root Lasso decoder with its minimization problem
  (lines 264-274, printed as Definition 2.1), the robust recovery guarantee for that decoder (lines
  322-328, printed as Proposition 2.5) and the vector-level recovery error proposition (lines 371-383,
  printed as Proposition 2.7). Every retained line is the article's own line, unchanged; nothing was
  omitted from any retained span, so the package carries no omission record and declares no adaptation.
* Numbering as delivered: the wrapper keeps the article's theorem-like environments on one shared counter
  but without the article's section-based prefix, so the retained items print as Definition 1, Proposition
  2, Proposition 3 and Theorem 4 in order of appearance, whereas the article prints the same four items as
  Definition 2.1, Proposition 2.5, Proposition 2.7 and Theorem 2.8; the numbered displays of the retained
  lines print consecutively in order of appearance, whereas the article numbers its equations per section.
* sources/175107/source0.tex - the complete native author source of the article as distributed in the arXiv
  e-print for this version. It is the mechanical concatenation of the article's five own source files (its
  main file and the four section files) in the order in which the main file reads them, byte identical to
  those files apart from the single header comment line the pipeline prepends.
* an AMS amsart wrapper, its standard TeX Live packages including the standard cleveref package that the
  article itself uses for its cross-references, and this notice. These are editorial formatting only; the
  article was typeset with the standard article class.

WHAT THIS PACKAGE DOES NOT CONTAIN
No image and no artwork: no retained line contains a figure environment or an image-inclusion command, and
the retained text contains no TikZ or drawing code; the package declares no asset dependency. (The article's own numerical illustrations and
plots lie outside every retained span.) No bibliography and no bibliography entry: no retained line
contains a citation. No publisher class or style file, no upstream script, no font and no unrelated
artwork from any other source. No content was deleted from any retained span.

The mathematical text is unchanged: no mathematics is written, repaired or re-derived, and the wrapper adds
only the editorial material described in the document's own scope paragraph.

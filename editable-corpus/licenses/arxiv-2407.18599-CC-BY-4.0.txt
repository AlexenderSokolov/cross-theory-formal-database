1. WHAT IS RETAINED IN THIS PACKAGE
-----------------------------------
This package is an editable LaTeX projection of one theorem or proposition of the Work, delivered with its
complete original proof and with the source-local context required to read it. It retains:

  * the authors' own LaTeX source text, reproduced verbatim from the e-print source file source0.tex at the exact line spans recorded in delivery-evidence.json (method "exact_tex" throughout, with no replacement and no omission);
  * the authors' own macro block, copied verbatim from their configuration file (source0.tex lines 50-142);
  * the authors' own archive/paper switch \ifpaper with \paperfalse, exactly as the published version uses it;
  * the authors' own bibliography entries, transcribed verbatim from the e-print file main_iota.bbl with the article's printed bibliography numbers;
  * the authors' own numbering, one independent counter per theorem-like environment as in their own class, so that the counted theorem is printed as Theorem 4, the preceding lemmas as Lemma 13 and Theorem 3 and the two recalled data-structure environments as Observation 1 and Observation 2, as in the published version;

2. EDITORIAL ADDITIONS (NOT AUTHOR MATERIAL)
--------------------------------------------
  * the AMS amsart wrapper preamble and page geometry supplied by the pinned runtime of this corpus;
  * the title block, the source-and-licence line and the editorial scope note at the head of the delivered item;
  * a registered class replacement: the Work's own document class is the Springer LNCS class llncs with the runningheads, UKenglish, cleveref, autoref and thm-restate options; that class file is not present in the pinned runtime and is NOT redistributed here, so the unit is delivered inside the AMS amsart wrapper with the authors' own macros, environments and numbering convention re-declared;
  * a proof-environment shim: the authors' own class prints no automatic end-of-proof symbol, so the wrapper proof environment is set not to add one and the class square-cap/square-cup mark is used for the authors' own \qed commands, which therefore appear exactly where the article prints them;

These additions are formatting, provenance and runtime-compatibility only. No mathematical statement, proof
step, symbol, hypothesis or number of the Work has been written, repaired, re-derived or altered, and the
printed slips of the Work are kept literal.

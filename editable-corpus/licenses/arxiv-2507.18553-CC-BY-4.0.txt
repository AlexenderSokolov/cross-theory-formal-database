WHAT THIS PACKAGE CONTAINS
* items/182160_author_proof.tex - one independent LaTeX document that reproduces, verbatim and in the
  article's own notation, the article's theorem thm:obq_babai (native source lines 426-430) together with the article's
  complete proof of it (lines 431-470, one proof environment of 40 lines). Retained uncounted as the source-local context the proof needs: lines 188-191; lines 418-424.
  One declared adaptation: the 1 image-inclusion commands inside the retained spans are omitted, so exactly 1 lines of the retained spans differ from the source and no other line does; the figure environments themselves, with their placement, captions and labels, are kept, and the package records the omitted strings in the fidelity receipts bound to the affected bodies. No image is delivered and the package declares no asset dependency.
* Numbering as delivered: the wrapper declares the retained theorem-like environments on separate counters, so the retained items print as Theorem 1 in order of appearance, whereas the article prints the same items with the numbering of its own full document; the numbered displays of the retained lines print consecutively in order of appearance, whereas the article numbers its equations per section.
* No bibliography and no bibliography entry: no retained line contains a citation.
* Drawing material: the retained lines contain the article's own diagram code, which the wrapper typesets with the standard tikz packages; no image file is delivered.
* sources/182160/source0.tex - the complete native author source of the article as distributed in the arXiv e-print for this version. It is the article's own source as the pipeline concatenated it, byte identical to the e-print files apart from the single header comment line naming them; nothing else is added, removed or changed.
* an AMS amsart wrapper, its standard TeX Live packages, and this notice. These are editorial formatting only.  The article's own local macro style file fancyhdr.sty, iclr2026_conference.sty, natbib.sty is shipped in the e-print; it is not redistributed here, and the wrapper restates only the declarations and macros that the retained lines use, copying them verbatim from that file.
